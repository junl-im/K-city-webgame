# 라니 수비대 v5.2 — 제1장 몬스터·보스 재검토 및 실전 원화

기준: v5.1의 12개 스테이지, 모든 세이브, 제2장 굴착과 제3장 공명파는 유지. 이미지·기능은 `ForestGuard` 안에서만 독립 관리. SVG 없음.

## 변경 결정

| 상대 | 판단 | 반영 내용 |
|---|---|---|
| 첫 공세 새싹 괴물 | 유지 | 기존 저속·다수 실루엣이 첫 영웅 한 명의 자동 공격과 잘 맞으므로 성급한 교체를 피함 |
| 2공세 달리는 버섯 | 유지 | 간격을 둔 빠른 2기가 이동속도 차이를 알려주는 역할. 초반부터 난전이 되지 않도록 원래 수 유지 |
| 3공세 가시 딱정벌레 | 유지, 이후 별도 디테일 후보 | 첫 작은 고속 정찰병으로 차별화. 현재 자체 피격 프레임을 유지하되 실기기 320px 인지성 추가 검수 필요 |
| 첫 스테이지의 8공세 버섯 거한 | 유지 | 전용 4포즈 공격 아트가 있으며 튜토리얼 마지막 정예. 장 전체 최종보스와 혼동되지 않도록 정예로 표기 |
| 제1장 중간보스 숲길 파수꾼 | **원화 교체** | 갑옷을 입은 사슴형 창·방패 파수꾼 2×2 투명 WebP, 공통 6프레임 공격/피격/사망 연결, 가시창 발사 후 단일 피해 |
| 1-4 최종보스 뿌리 거인 | **원화 교체** | 고목과 바위가 결합한 거대 실루엣, 진격·뿌리 강타·피격 2×2, 세 갈래 뿌리창이 성벽에 닿은 뒤 1회 피해 |

## 아트와 표시

- `art/chapter1-forest-sentinel-v52.webp`: 1263×1246 원본에서 WebP 변환. 390px 캡처 역검수에서 파수꾼의 어두운 명암을 발견해 노랑·이끼색 윤곽광을 보정. 제1장 1-1~1-4의 중간보스에만 사용. 다른 장의 기존 파수꾼 아트에는 영향 없음.
- `art/chapter1-root-giant-v52.webp`: 1266×1242 원본에서 WebP 변환. 1-4에만 사용.
- 둘 다 좌상=대기, 우상=전진, 좌하=강공격, 우하=피격/후속 자세. 컷신의 216px 확대에서 흐려지지 않도록 원화 프레임을 128px에서 224px로 변경. 원본 종횡비 유지 및 잔여 배경 픽셀 제거. 이 변경은 이 4포즈 보스·파수꾼 프레임에만 적용.
- 보스 체력 HUD 초상도 시트 좌상단을 사용, 원화 외곽에 CSS 테두리·중첩 프레임 추가하지 않음.
- 무기 공격 효과는 `boss-root-spear` 56×154 원본 Canvas 텍스처 하나를 재사용. 매 틱 새 그림을 만들지 않고 필요한 순간에만 표시.

## 공격의 예측 가능성

- 파수꾼: 1,250ms 지상 예고 후 가시창 비행, 도달 시 성벽 -45. 기존 다른 장 파수꾼의 충격파 동작은 유지.
- 뿌리 거인: 1,250ms 지상 예고 후 뿌리창 세 갈래. 앞의 두 갈래는 경로 연출이며 **세 번째 도착에만** 기본 -55 또는 격노 -75. 성벽 보호 시 -32. 돌진 속도 증가는 1,100ms로 제한.
- 예고 중 수동 일제사격으로 취소 가능한 기존 규칙과 격노 체력 50% 기준은 그대로 유지.
- `prefers-reduced-motion` 시 뿌리창 이동을 간략화하고 카메라 흔들림 생략.

## 남은 디자인 과제

가시 딱정벌레의 320px 가독성과 입장 시 몬스터 방향/속도(적은 화면 상단 → 성벽 방향)를 실기기에서 장시간 재검수. 피격 모션은 보존하고 필요 시 아틀라스의 해당 1종만 독립 원화로 개선. 예술적 퀄리티 향상 때문에 첫 스테이지의 안전한 웨이브 밸런스를 희생하지 않음.
