# 라니 수비대 디자인 MASTER v2.1

기준: 2026-11-01 사용자가 공유한 프리뷰 2809.png의 홈·스테이지·영입·전투·결과 그림을 실제 게임의 최종 아트 목표로 사용한다.

## 실제 수정된 내용
- 홈 12개 빈 노드 제거, 숲길 원화의 현재 스테이지 카드와 독립 스테이지 화면 도입.
- 스테이지 화면에는 이름/진행/잠금 리스트, 연속 원화 지도, 선택된 장면 정보, 돌아가기·출전 버튼 연결.
- 배경 원화 이중 렌더 제거: arena-wrap의 외부 backgroundImage 없음. Phaser field 하단에서 잘라 다시 쌓는 fort-foreground 제거.
- 스테이지 12개, 1인 시작, 12초 자동 영입, 기존 세이브와 특수 몬스터 기술 보존.
- 디자인 방향은 숲·나무·황동·일러스트 소재. SVG 불허, 레거시 이모지나 도형형 빈자리 복귀 금지.

## 반드시 계속 진행할 것
- 전용 투명 성벽 원화/영웅 원화/몬스터 독립 프레임을 연결해 프리뷰의 깊이와 공격 동작을 재현.
- 결과창 별·보상·다음 스테이지·귀환을 실제 동작하는 화면으로 리셋.
- 누적 63KB style.css 중복 스타일을 테마/홈/지도/전투로 구조 분리.
- Android 삼성 인터넷과 iOS Safari 실기기, 전체 스테이지 완주율과 FPS/발열 검증.
