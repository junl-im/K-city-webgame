# 라니 수비대 v5.1 — 장별 보스 원화·패턴과 제1장 재검토

개발 계승: `codex/forestguard-v508-attack-release`; 실제 반영 기준: 2026-11-06 최신 `main`. 다른 게임 폴더·저장 데이터 키는 변경하지 않음.

## 확정 적용

| 구간 | 원화·전투 | 구분 목적 |
|---|---|---|
| 1-1 첫 번째 침입 | 첫 공세 새싹만, 2공세는 새싹+간격을 둔 달리는 버섯 2기, 3공세부터 가시 정찰병 보장 | 새 유저의 첫 3공세를 단계별 학습으로 구성 |
| 제1장 중간보스 | 기존 숲길 파수꾼(guardian)을 유지, 화면의 이름을 통일 | 뿌리 거인과 다른 실루엣의 중간 관문 |
| 제1장 1-4 최종보스 | 기존 뿌리 거인 유지, 돌진 시 흙빛 파동 보강 | 독립 원화 미제공이므로 임시 교체 금지 |
| 제2장 2-4 | 가면 두더지 2×2 원화를 6프레임 전투 상태로 연결 | 좌우 굴착, 출현 위치 경고, 성벽 지하 진동 피해 |
| 제3장 3-4 | 검은 종의 주인 2×2 원화를 6프레임 전투 상태로 연결 | 전진하는 보랏빛 3연속 공명파, 마지막 파동에 피해 적용 |

두 보스 공통으로 절반 이하 체력에서 격노 상태에 들어가며 능력 간격이 단축됨. 스킬 일제사격으로 경고 상태를 저지할 수 있음. 제2장 굴착 중에는 일시적으로 표적 불가이며 출현 지점이 사전에 표시됨. `prefers-reduced-motion` 선택 시 공명 파동은 빠르게 처리함.

## 제1장 원화 역검수 판단

- **일반 몬스터**: 새싹·달리는 버섯·가시 딱정벌레를 1-1의 핵심 3종으로 유지. 현재 실루엣의 식별성은 있으나 더 높은 원화로 교체하려면 실제 320px 화면에서 혼전 중 인지가 되는지 별도 검증 필요.
- **중간보스**: 숲길 파수꾼은 버섯 거한/뿌리 거인과 역할이 다르므로 당장 제거하지 않음. 다만 전 장에 같은 원화가 등장하므로 향후 장별 중간보스 독립 일러스트가 필요.
- **최종보스**: 뿌리 거인은 제1장의 나무뿌리 테마와 맞아 유지. 제2·3장의 신규 보스에 비해 독립 포즈 원화가 부족하므로 다음 자산 제작 우선순위 1순위.
- **구성 문제**: 1-1에 정예와 중간보스가 동시에 있지는 않음. 5공세 파수꾼, 마지막 8공세 버섯 거한으로 구분하여 초반 기대감을 학습시킴.

## 자산 규격과 성능

- `art/chapter2-masked-mole-v51.webp`, `art/chapter3-black-bell-v51.webp`는 사용자 제공 투명 PNG의 WebP 압축본. 원화 변경·제3자 캐릭터 차용 없음.
- 각 시트 2×2: 좌상=대기, 우상=진격, 좌하=강공격, 우하=후속 자세. 사망·피격은 기존 공통 모션 타이밍에 맞춰 활용.
- 해당 보스 스테이지에 진입할 때만 선택적으로 시트를 로드. 로딩 실패 시 이전 보스 아틀라스가 남아 전투가 진행되는 폴백 유지.
- 128×128 Canvas 텍스처를 배틀 시작 시 1회 생성. 매 프레임 새 Canvas 생성하지 않음. 원본 비율 유지, SVG 없음.

## 남은 검수

- Chromium에서 320/360/390/430px 및 PC 실제 화면 확인, 보스 초상·전투 애니메이션 구도·경고 영역 중첩 검사.
- 2-4/3-4까지 정상 해금 흐름으로 진입하여 격노·스킬 저지·보스 처치·후속 결과창 실기기 확인.
- 제1장 보스 신규 원화가 확정되면 기존 기본 `boss` 아틀라스를 대체하고 모든 상태 프레임 검수.
