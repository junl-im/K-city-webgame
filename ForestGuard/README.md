# 라니 수비대

곰같은여우의 모바일 우선 로그라이크 성벽 디펜스 웹게임.

**상태: v0.8 지역별 전투 원화·부채꼴 진입로·보스 경고 개선.** 기존 v0.2의 원화·전투·저장 구조를 보존하면서 5상태 모션 프레임, 전용 PNG 아이콘, 3보스 행동 예고·저지, 강화 조합을 추가한 플레이 테스트용. 관절별 고급 원화 스프라이트와 실기기 QA는 후속 작업.

## 플레이
- index.html을 정적 웹서버(HTTP)에서 엽니다. 최초 접속에는 Phaser 3 CDN 연결이 필요합니다.
- PC와 스마트폰 모두 터치·클릭만으로 동작합니다.
- 시작: 여우 궁수+곰 수호자 / 성벽 HP 3,000
- 여우 사격 적중으로 진화 에너지 10을 모으면 버튼을 눌러 큰 여우 '곰같은여우'로 진화합니다.
- 진화형은 8프레임 공격 스프라이트·더 긴 사정거리·다중 발사·강한 공격력을 사용합니다.
- 용병마다 실제 거리 계산을 적용해 공격 가능 범위 안의 적만 노립니다.
- 2웨이브마다 3개 카드 중 1개 강화. 한 번 무료 재추첨.
- 일제사격 버튼은 몬스터에게 범위 피해와 둔화를 줍니다.
- 용병 칸 두 개를 순서대로 탭하면 위치를 교환합니다.
- 12스테이지 설계, 각 챕터 4번째 스테이지가 보스. 순차 잠금 해제.
- 진행 기록은 브라우저 localStorage에 저장됩니다.
- 전투 중 홈/뒤로가기는 지도로 돌아오며 '이어서 싸우기'에서 계속할 수 있습니다.

## v0.3에서 추가한 기능
- **모션 5종:** 기존 독자 PNG 원화에서 대기·달리기·공격·피격·승리 프레임을 Canvas로 생성. 여우·곰·토끼·고양이·진화 여우·일반 적·보스 공통. 정교한 관절 애니메이션 원화는 이후 별도 제작.
- **전용 UI:** Canvas로 생성한 PNG 문양을 사용해 시작·귀환·일시정지·스킬·진화·강화 카드·잠금 아이콘을 교체. 전열 초상은 원본 PNG 캐릭터 시트에서 표시. SVG와 시스템 이모지 미사용.
- **보스 고유 패턴:** 뿌리 거인의 돌진, 가면 두더지 잠복·위치이동, 검은 종의 성벽 파동. 1.25초 예고 후 발동하며 일제사격으로 저지 가능.
- **성장 분기:** 불꽃+속도=화염폭풍, 서리+번개=빙뢰연쇄, 다중 화살+치명타=폭풍 화살, 성벽 카드 2회=불굴의 성벽.
- **전장:** 2장 안개 시각 효과, 3장 달빛 색조, 2장 단단한 적 비율 강화, 수정 연못 갑옷 피해 감소.

## v0.6 전투 시스템 진화 (2026-10-31)
- **진화 분기**: 여우 진화 에너지 10에서 햇살(강화 공격·불꽃 범위 피해) 또는 달빛(사거리·연사·둔화) 두 갈래를 선택. 기존 독자 원화의 색조만 사용, 신규 외부 원화 없음. 선택창 닫기·뒤로가기로 전투 복귀 가능.
- **전술 강화 4종**: 덩굴 덫(주기적 구속), 관통 화살(갑옷 방어 무시), 숲의 수호(공세당 성벽 피해 차단·소량 회복), 추적의 눈(사거리·보스 대응·안개 시야).
- **신규 시너지 2종**: 덩굴+불꽃=불꽃 덩굴, 수호+성벽=고목의 맹세. 기존 4종 조합 유지.
- **조합 후보 제안**: 강화 3지선다에서 보유 카드의 짝을 확률적으로 노출. 무작위 배열은 Fisher–Yates 섞기로 변경. 무료 재추첨 유지.
- **전장 특성**: 부서진 다리 좁은 진입로, 포자 군단의 주기적 증원, 바람의 언덕·마지막 밤 적의 횡이동, 안개 사정거리 감소, 기존 수정 갑옷을 관통으로 대응.
- **방향**: 과금·광고·기간 제한 없이 무작위 성장의 재미와 플레이어 선택권을 함께 유지.
- **검증 범위**: 소스 문법·정적 smoke·공개 브라우저 기본 플레이를 확인할 수 있으나, 320px 실기기와 12스테이지 전체 밸런스는 별도 QA 필요.
- **비교·오픈소스 조사**: SYSTEM_RESEARCH_V06.md 참조.

## v0.7 간결한 UI와 몬스터 정찰 (2026-10-31)
- **메뉴 버튼**: 불필요한 전체 폭 시작 버튼을 폐지하고 시작(104px)·이어하기(91px)·도움말(87px)을 중앙에 배치. 좁은 화면에서도 세 버튼을 한 줄에 배치하도록 설계하고 터치 높이 44px 유지.
- **전투 버튼**: 하단 용병·진화·일제사격 버튼을 약간 압축해 원화 전장이 더 드러나도록 정리. 필수 조작·뒤로가기·저장 호환 유지.
- **정찰 수첩**: 스테이지 설명의 작은 `적 정보` 버튼으로 해당 전장의 위험, 실제 출현할 적 유형과 대응 카드를 확인. 자체 제작 `forest-characters.png` 원화 초상 재사용.
- **실제 상성**: 바위 갑옷 적은 기본 일반 화살 피해 18% 감소(수정 연못은 30%). 관통·마법으로 대처. 새싹 적은 불꽃 화상 피해 25% 추가. 빠른 적은 기존 둔화·덩굴로 제어, 보스는 일제사격 경고 저지.
- **미완 QA**: 320px Android/iOS 실기, 12개 스테이지 전수·보스 진화 양쪽 완주 및 게임 밸런스 측정. 추가 외부 원화·SVG 없음.

## v0.8 — 넓은 진입부에서 좁은 방어선으로 (2026-10-31)
- 숲의 입구(1~4), 안개 협곡(5~8), 달빛 고원(9~12)에 맞춘 **독자 PNG 전투 원화 3종** 추가. 이 3종을 각 구간의 바탕으로 사용하며, **12개 스테이지 완전 개별 원화가 완성된 상태는 아님**.
- 모든 배경의 상단은 넓고 하단은 좁은 부채꼴 전장. 적 스폰은 상단 좌우 전체에 펼쳐지고, x 좌표가 아래 방어선으로 갈수록 자연스럽게 수렴. 갈라진 숲길은 양쪽 진입 유지.
- 뿌리 거인/두더지/검은 종 보스에 경고 링·잔여 시간 막대·테두리 경고를 추가. 일제사격 저지·처치 때 연출 정리.
- 기존 `forest-battleground-v04.webp`와 Canvas 배경은 새 PNG 로드 실패 시 대체. 3지역 PNG는 현재 스테이지에 필요한 것만 지연 로드해 모바일 데이터 사용을 줄임. SVG 없음.
- 남은 검사: 320px Android 실기기, 3보스 풀플레이, 12개 스테이지용 완전 개별 원화, 실제 성능 계측.
