# 숲끝 수비대 / Forest Guard

곰같은여우의 모바일 우선 로그라이크 성벽 디펜스 웹게임.

**상태: v0.1 전투 뼈대.** 용병·몬스터·스테이지·강화 카드·보스·저장을 구현한 초기 플레이 테스트용. 최종 전용 원화·이펙트·사운드·성능 검증은 후속 개발 항목.

## 플레이
- index.html을 정적 웹서버(HTTP)에서 엽니다. 최초 접속에는 Phaser 3 CDN 연결이 필요합니다.
- PC와 스마트폰 모두 터치·클릭만으로 동작합니다.
- 시작: 여우 궁수+곰 수호자 / 성벽 HP 3,000
- 2웨이브마다 3개 카드 중 1개 강화. 한 번 무료 재추첨.
- 일제사격 버튼은 몬스터에게 범위 피해와 둔화를 줍니다.
- 용병 칸 두 개를 순서대로 탭하면 위치를 교환합니다.
- 12스테이지 설계, 각 챕터 4번째 스테이지가 보스. 순차 잠금 해제.
- 진행 기록은 브라우저 localStorage에 저장됩니다.
- 전투 중 홈/뒤로가기는 지도로 돌아오며 '이어서 싸우기'에서 계속할 수 있습니다.

## 코드 및 디자인
- 게임 프레임워크: Phaser 3.88.2 (MIT).
- 참고 오픈소스: https://github.com/rupertgermann/tower-defence (MIT), 특히 웨이브 관리·적 처리·투사체 처리 패턴. 원작의 가로형 타워 배치 대신 고정 성벽형 로그라이크 용병 전투로 새 설계.
- 이미지: v0.1 화면에서는 자체 Canvas 2D 페인팅 텍스처를 생성. SVG 없음. UI 일부 시스템 이모지는 임시이며 다음 제작 단계에서 전용 PNG/WebP로 교체 예정.
- 운영: 정적 웹 호스팅 가능. 서버·로그인·광고·인앱 결제 불필요.
- 분리: K-city-webgame/ForestGuard/ 단독 진입점. 다른 게임 소스·에셋은 수정하지 않음.
