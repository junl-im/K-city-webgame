# 라니 수비대 개발 규칙

- 다른 K-city-webgame 게임과 소스·원화를 섞거나 덮어쓰지 않는 독립 프로젝트.
- 소스·디자인·콘텐츠 권리 표기는 '곰같은여우'만 사용한다. 개인 실명 금지.
- 모든 SVG 금지. 배경·프레임·버튼·아이콘은 독자 PNG/WebP 또는 Canvas로 만들고 임시 이모지는 교체한다.
- 모바일 세로 한 화면 우선. 불필요한 스크롤·가로 밀림·우클릭·드래그 필수조작 금지.
- 에너지 제한·강제 광고 없이 무료 플레이.
- 루트 AGENTS.md의 뒤로가기·취소·나가기·직접 접속 규칙을 지킨다.
- 완료 선언 전에 실제 브라우저, Node smoke, 스테이지 및 터치 QA 검증.
- 외부 MIT/CC0 콘텐츠의 각 라이선스·출처를 기록하고 다른 게임의 원화를 사용하지 않는다.

## 프리뷰 기준 디자인 규칙 — 2026-11-01
- 사용자 제공 마지막 프리뷰(홈·스테이지 선택·동료 선택·전투·결과)를 시각적 기준으로 고정한다.
- 홈에는 실제 영웅 로고와 큰 시작 버튼을 표시한다. 빈 스테이지 노드를 흩뿌리지 않는다.
- 스테이지는 별도 화면에 이름·잠김·클리어·출전·뒤로가기를 갖춘다.
- 전투에는 한 장의 일러스트 배경만 사용한다. Phaser 캔버스 뒤에 동일 사진을 또 넣거나, 배경 하단을 다시 잘라 겹치는 것 금지.
- 성벽에는 전용 투명 원화를 쓰며, 영웅 발밑 뒤로 배치한다. SVG 전면 금지.
- 기능이나 저장 데이터 퇴화 금지. 결과창도 프리뷰 수준으로 재제작해야 하며 아직 완료되지 않았다.
- 최소 320·360·390·430px 모바일과 PC에서 화면 캡처/스크롤/버튼 겹침/전투 전환을 확인한다.
- 63KB 누적 CSS의 중복 선택자를 다음 리팩터링에서 정리하고 실제 게임 화면 검증 후에 완료를 선언한다.
