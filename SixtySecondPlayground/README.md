## 파일 구성

- `dist/index.html` — 홈 및 7가지 게임 선택 화면
- `dist/style.css` — 원화 기반 UI와 모바일 대응
- `dist/app.js` — 60초 게임, 공식 도전, 브라우저 기록
- `dist/assets/*.webp` — 배포용 경량 일러스트
- `tests/smoke.cjs` — 오프라인 회귀 검사
- `source-assets/*.png` — 편집용 고화질 PNG 원본 21개(약 43.6MB), GitHub 이전 및 해시 검증 완료

## 개발 및 배포

1. 이 폴더에서 실행 파일과 원화를 수정합니다.
2. `node SixtySecondPlayground/tests/smoke.cjs`로 7개 게임과 에셋의 기본 검사를 실행합니다.
3. `main`에 반영하면 저장소 루트의 `.github/workflows/magic-garden-pages.yml`이 마법정원과 이 놀이터를 **서로 다른 경로로** 묶어서 GitHub Pages에 게시합니다.
4. 마법정원 공식 홈은 `/`, 60초 놀이터는 `/SixtySecondPlayground/`입니다. 놀이터 수정 시 마법정원 게임 소스는 건드리지 않습니다.

모든 이미지·CSS·JS는 상대 경로를 사용합니다. 게임 기록은 이용자 브라우저의 localStorage에 남고, 서버 계정이나 별도 API 키는 없습니다.

### 기억왕 화면 안정화 (2026-10-29)

기억왕은 라운드마다 게임판을 다시 만들지 않고 유지하며, 작은 화면에서도 별과 물음표 전환 시 칸 크기를 고정합니다. 별 강조는 반복 점멸 대신 고정 테두리로 표시합니다. 타이머 표시는 값이 바뀔 때만 갱신합니다.

### 저장 실패 처리 (2026-10-29)

공식 도전 시작 기록을 저장할 수 없으면 자유 플레이로 진행하며, 종료 기록 저장에 실패하면 결과 화면에 알려 줍니다. 기존 로컬 저장 형식은 유지합니다.

### 같은 브라우저의 여러 탭 기록 보호 (2026-10-29)

공식 도전 시작과 결과 저장 전에 다른 탭의 최신 기록을 확인하고 최고 점수·플레이 횟수·도전 이력·배지를 병합합니다. 다른 탭에서 변경되면 표시도 갱신합니다. 서버 동기화는 제공하지 않습니다.

### 게임 중 뒤로 가기 보호 (2026-10-29)

게임 중 브라우저 뒤로 가기를 누르면 현재 판을 일시정지하고 기존 나가기 확인 화면을 표시합니다. 계속하기를 누르면 게임과 타이머를 재개합니다.

### 게임 판정과 접근성 점검 (2026-10-29)

다른 그림 찾기의 기준판과 선택 칸을 화면낭독기가 순서대로 읽을 수 있도록 이름을 제공하며, 미스터리의 모호한 문제 한 개를 명확하게 수정했습니다.

### 제한 시간 경계 보호 (2026-10-29)

화면 타이머의 다음 갱신을 기다리지 않고, 각 게임의 입력 시점에 제한 시간이 지났는지 확인해 종료 후 점수가 추가되지 않도록 합니다.

### 자정 전후 오늘의 도전 (2026-10-30)

공식 도전 안내를 열어 둔 사이 한국시간 날짜가 바뀌면 새로운 오늘의 게임을 다시 안내합니다. 이미 시작한 게임의 결과는 시작한 날짜에 기록합니다.

### 모바일 게임 화면 안정화 (2026-10-30)

게임 시작 전 안내창·일시정지창 및 게임판의 반복 움직임, 화면 전체 흔들림과 흐림 합성을 줄였습니다. 기존 그림과 정답·오답 색상 및 점수 안내는 유지합니다.

### 빠른 문제 전환과 재도전 (2026-10-30)

문제 간 정답·오답 확인 시간은 게임별 기존 값으로 유지합니다. 기억왕은 별이 표시될 때 바로 선택하거나, 별이 사라진 뒤 기억한 위치를 선택할 수 있습니다. 이전에는 별이 사라진 뒤에만 선택할 수 있었으므로 이전 최고 기록과 직접 비교할 때 이 차이가 있습니다. 결과의 ‘한 판 더!’는 같은 게임의 자유 플레이를 즉시 시작합니다.
