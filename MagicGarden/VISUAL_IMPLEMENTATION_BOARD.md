### 완성 판정 원칙
1. **원화 품질 = 사용자가 승인한 3장의 실사이즈를 대조**하여 평가.
2. **기능 구현 완료 여부 = 코드/자동 검사 + 실제 플레이 확인**으로 평가; 예쁜 목업과 혼동 금지.
3. **사이트 배포 완료 여부 = 실제 운영 버전 확인**으로 평가; GitHub 커밋만으로 배포 완료 주장 금지.
4. **새로 생긴 임시 기본 도형·이모지·일반 아이콘을 발견하면 완성으로 표시하지 말 것.**
