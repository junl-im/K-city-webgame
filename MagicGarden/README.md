# 곰같은여우의 마법정원 — 첫 플레이 프로토타입

2026-10-27 / Magic Garden 기획 v0.1을 바탕으로 한 **중앙 마을 ↔ 큰 텃밭** 작동 검증용 게임.

## 실행

Node.js 및 npm 필요.

```bash
cd MagicGarden
npm install
npm run dev
```

빌드: `npm run build`, 로컬 확인: `npm run preview`

## 구현된 기능

- 터치/클릭 위치로 여우 이동, 귀여운 4마리 동물 캐릭터 (절차적 Canvas 비트맵)
- 중앙 마을 / 큰 텃밭 구역 전환과 상황 안내
- 12개 텃밭에 파종·성장·수확 (18초 단축 실험 속도)
- 씨앗·열매 재고, 가방·지역 목록·도감·도움말
- 브라우저 로컬 저장(프로토타입 단계), 모바일 세로 화면 카메라 추적
- 앱 소스/배포 자산에 벡터 이미지가 섞이지 않는 검사 스크립트

## 고품질 원화 적용 (2026-10-27)

- `public/assets/town-scene-v1.png` — 마을, 폭포, 물레방아, 다리, 오솔길 고화질 원본 비트맵
- `public/assets/farm-scene-v1.png` — 넓은 텃밭, 숲, 풍차, 농가 고화질 원본 비트맵
- 각 구역에 진입할 때에만 해당 원화를 비동기 로드한다. 다운로드를 못 하는 경우에는 기존 절차적 Canvas 배경으로 작동한다.
- 원화는 단일 PNG이므로 현재 자연물·건물과 캐릭터 사이 **앞뒤 가림(오클루전), 지형 충돌, 실제 3D 카메라**는 구현되지 않았다. 다음 단계에서 레이어 분리와 충돌 지도를 제작한다.
- PNG 원본은 약 3MB 이상이므로 향후 WebP/AVIF 저용량 버전을 별도 제작해 모바일 우선 제공할 예정이며, 최적화 완료로 표시하지 않는다.
- `vite.config.ts`에 `base: './'`을 넣어 AI 놀이터 하위 경로에서 정적 파일 경로가 유지되도록 했다.
- 이미지 제작 방식: 내장 이미지 생성 도구 기반 자체 게임 배경 원화 2장 (원본 참고 이미지는 화풍용).

## 구분해서 봐야 할 것

- 고화질 원화 배경 2장을 추가했지만, 동물 캐릭터와 작물은 **절차적 비트맵 임시 자산**이며 사용자가 기대하는 통일된 최종 2.5D 아트 완성본은 아님. 향후 레이어형 씬과 렌더링된 WebP 스프라이트셋으로 교체 예정.
- 조합 실험실, 몬스터 부화/육성, 숲·폭포·다리, 실제 지형 충돌, IndexedDB, PWA, 오디오, 진짜 자동 동기화는 아직 구현 전.
- 기존 루트 Soul Online 프로젝트와 독립적으로 동작하도록 하위 폴더에만 작성. 기존 main 브랜치 및 Firebase 설정은 변경하지 않음.
- 외부 CDN이나 유료 AI API 호출 없음. 앱 작동에 외부 서버 필수 아님.
- 아트·UI·라이브러리에서 SVG 렌더링 및 SVG 파일은 어떤 용도로도 사용 금지.

## 향후 QA

1. `npm run build` 통과와 그래픽 리소스 검사 (현재 실행 환경에서는 미실시 — 반드시 별도 검증)
2. PC 마우스, Android 터치, iPhone Safari 터치 테스트
3. 새로고침/지역 전환/탭 재접속 후 저장 복원
4. 텃밭 전부 심기→수확→재파종 루프
5. 세로/가로 회전, 주소창 움직임, 하단 UI 겹침 확인
