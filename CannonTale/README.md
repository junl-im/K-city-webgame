# 캐논테일 (CannonTale) — 웹 플레이어블 v1.1.1

**게임 이름은 가제이며, 최종 확정 전에도 저장 데이터와 주소를 보존하기 위해 개발용 폴더명 `CannonTale/`을 고정합니다.**

《캐논테일》은 두 종류의 포물선 놀이를 동등한 비중으로 묶은 2D HTML5 게임입니다.

- **모험 포격:** 직접 조준해 나무와 돌 요새를 무너뜨리는 물리 퍼즐. 4개 지역 지도와 지역별 바람, 최종 보스.
- **포격 결투:** 각도·파워·바람을 읽으며 AI와 번갈아 벌이는 턴제 결투. 쉬움/보통/어려움.
- **영웅 4명:** 여우 탄도 보정, 곰 관통, 토끼 오중 분열, 고양이 바람 전환.
- **입력:** 모바일과 PC 터치/포인터, 터치 영역을 넓힌 조준 슬라이더, 스페이스 발사, Q 특수기, 게임 내 조작법.
- **v0.8 시각 개선:** 지역에 따라 변하는 적 4종의 신규 원화, 피격 반응, 캔버스 예상 궤적 및 구조물·적·지면 충돌점 표시, 탄종별 시각 구분.
- **v0.9 손맛 개선:** 몬스터 대기·피격·사망 전환, 나무·돌·철 구조물의 3단계 수작업 캔버스 재질·균열 묘사, 포신 반동·화염·충격파·먼지, 무기별 결투 AI 전술, 모바일 세로·가로 화면별 조작 패널 배치.
- **v1.0 원화 연결:** 업로드한 그림을 WebP로 경량화하여 목재·석재·철재를 손상 3단계(멀쩡함/균열/심각 파손)별 실제 원화로 교체. 체력 임계점마다 파편·불꽃이 추가로 발생합니다. 4지역 지도와 첫 등장 연출에는 도토리 수호병·이끼 바위거인·바람의 정령·강철 화염대장의 신규 일러스트가 등장합니다. 새 몬스터 시트는 배경이 포함되어 있어 전투 중에는 기존 투명 원화와 물리 충돌 처리를 유지하며, 추후 배경 분리 후 전투 스프라이트로 교체합니다.
- **v1.1 포격 결과 확인:** 모든 탄착 후 착탄 지점을 카메라가 유지하고, 구조물 피해·몬스터 격파·결투 HP 변화를 보여 주는 결과 리본을 표시합니다. 모험은 사용자가 `다음 발사` 또는 `승리/도전 결과 보기`를 누르기 전까지 자동으로 발사점에 복귀하지 않으며, 결투는 결과를 3.5초 보여준 뒤 자동으로 다음 턴을 진행합니다. 최종 결과창에서는 `파괴 현장 보기`로 전장 관찰 후 다시 결과창으로 돌아올 수 있습니다.
- **v1.1 인터페이스 원화:** 독립 제작한 3×3 PNG 아이콘 아틀라스로 모드 카드·포탄 선택·발사·특수기·망원경·지역 지도를 갱신했습니다. SVG·이모지·외부 폰트는 사용하지 않습니다. 모바일 세로·가로의 버튼 비율과 여백을 따로 조정했습니다.
- **v1.1.1 몬스터 동작 후속 패치:** 도토리 수호병·이끼 바위거인·바람의 정령·강철 화염대장 4종 각각의 대기·공격·피격·쓰러짐 투명 배경 원화 총 16포즈를 추가했습니다. 피해를 받으면 공격 동작을 끊고 피격 동작으로 전환하며, 격파 시 쓰러진 모습을 잠시 유지합니다. 모험의 몬스터 공격 포즈는 현재 위협 연출이며 플레이어에게 직접 피해를 주는 기술은 아닙니다. 목재·석재·철재는 균열 단계에서 재료별 파편·섬광·충격파를 추가하고, 지면에 떨어진 파편을 현장에 남겨 포격 결과를 확인할 수 있습니다.
- **v1.2 포즈 전환 보정:** 기존 4종 × 4포즈 시트를 그대로 사용하면서 등장 착지 반동·공격 전방 기울임·대기 호흡·사망 회전과 눌림을 시간 기반으로 보정했습니다. 별도의 신규 다중 프레임 원화가 완성된 것은 아니며 실제 안드로이드 세로·가로 실기기 검수는 미완료입니다.
- **v1.2.2 전투 감각 후속 개선 (코드 반영/실기기 미검증):** 나무·돌·철 구조물의 파괴 시 재료 무게와 크기를 고려한 대형 잔해 생성, 충돌 시 카메라 흔들림 강화, 포탄 비행 완료 뒤 최소 1.35초간 붕괴 연출 유지. 착탄 결과에는 실제 파괴된 목재·석재·철재 개수를 표시하고 낙하 파편을 카메라가 미세하게 따라갑니다. 몬스터 4종에 잎·암석·바람·불꽃의 개별 공격 효과가 추가됐습니다. 9종 기존 수작업풍 비트맵 아이콘을 배경 없는 조작부에 배치하고 세로·가로 CSS 안전 영역을 보정했습니다. 새로운 독립 다중 프레임 원화는 아직 별도 완성되지 않았으며 기존 16개 키 포즈를 사용합니다. 스모크 테스트에 360×640/844×390 캔버스 크기 조건을 추가했고 GitHub에 저장된 Matter.js 0.20.0 엔진·게임 코드·테스트 파일을 직접 실행한 결과 통과했습니다. GitHub Actions CI 실행 결과 및 안드로이드 실기기 시각 검수는 별도로 확인되지 않았습니다. SVG 자산은 추가하지 않았습니다.
- **v1.2.3 첫 발사 이후 조작 잠금 긴급 수정:** 모험에서 첫 착탄 뒤 다음 포탄이 남으면 결과 확인을 유지하면서도 각도·파워·탄종·발사 버튼이 활성화됩니다. 각도/파워/탄종 변경 시 조준 상태로 전환하며, 발사 버튼을 누르면 별도의 `다음 발사` 클릭 없이 바로 두 번째 포탄을 쏩니다. 승리/실패 시에는 기존 결과 화면 확인 절차를 유지합니다. 궤적은 기존 희미한 점 대신 검푸른 외곽선+밝은 금빛 점선으로 대비를 높이고 착탄 표시도 두껍게 만들었습니다. 실제 Matter.js 0.20.0 엔진을 사용하는 스모크 테스트에서 첫 착탄 후 버튼 활성화, 두 번째 발사, 각도 변경, 궤적 렌더링을 검증했습니다. 실제 안드로이드 시각·터치 검수 및 이번 커밋 Pages 배포 완료 여부는 별도 확인이 필요합니다.
- **v1.2.4 모바일 첫 화면 단일 뷰포트 패치:** 모바일 세로 첫 화면을 스크롤 없이 보이도록 패널 높이를 화면에 맞추고 제목·원화·모험/결투 카드·설정·지도·기록·영웅 선택을 압축 배치했습니다. 짧은 세로 화면에서는 설명과 장식을 먼저 생략하며, 가로 화면은 일러스트와 선택 화면을 2열로 구성합니다. 안드로이드 브라우저 주소창/안전 영역 등으로 실제 높이가 부족해지면 메뉴의 높이를 측정해 2단계 압축 스타일을 적용하고, 회전해 넓어지면 원상 복구합니다. 첫 화면 상단의 불필요한 버튼을 숨기고 기존 SVG 없는 원화 버튼의 색감·선택 효과를 개선했습니다. 모험 모드에는 연속 타격 성공 시 결과 화면에 연속 명중 횟수를 표시하는 피드백을 추가했으며, 빗나가거나 새 게임을 시작하면 0으로 초기화됩니다. 기존 저장 데이터와 물리 엔진은 유지됩니다. Matter.js 0.20.0을 사용한 전체 코드 스모크 테스트 및 메뉴 밀도 전환 테스트는 통과했지만, 실제 안드로이드 크롬의 시각적 겹침·터치 테스트와 최신 Pages 배포 성공은 별도 확인이 필요합니다.\n- **v1.3 조준·방향·데미지·전환 개선 (2026-11-03):** Fox/Rabbit 원화는 기본 오른쪽, Bear/Cat 원화는 기본 왼쪽을 향하므로 플레이어/AI 시선에 따라 반전하는 렌더 규칙 추가. 도토리 수호병도 왼쪽 플레이어를 향하도록 반전. 모험에서는 기존 그림 속 각 캐릭터의 무기를 보존하고 중복 새총 덧그리기를 중단. 피해 수치가 실제 맞은 몬스터 및 결투 캐릭터 머리 근처에 표시되도록 개선. 발사 후 중앙에는 별도 텍스트 없이 숫자 카운팅을 표시(모험 7초, 결투 4초), 기존 조기 확인 버튼 유지. 전장 세로 드래그로 각도 조절, 수평 드래그로 카메라 이동. 조작부는 각도와 예상 수평 거리 표시, 발사 버튼 길게 누르면 파워 게이지가 오르내리고 놓으면 발사. 짧은 탭 또는 키보드 Space는 직전 파워로 즉시 발사. 대기/충전/발사 직후 버튼 상태 구분. 라이브 거리 미리보기는 넓은 포물선까지 샘플링. 원본 저장·물리 로직 보호. 리그레션 테스트에 4종 방향 규칙, 결투 피해 숫자 좌표, 위아래 드래그, 길게 누르기, 결과 카운트, 재발사를 추가했으며 Matter.js 0.20.0 기반 로컬 자동 실행 통과. 모바일 실기기/최신 GitHub Pages 배포 상태는 미확인입니다. 상세 자료와 다음 스킬 개발 계획은 [TECH_RESEARCH_V1_3.md](TECH_RESEARCH_V1_3.md) 참조. 결투 전용 무기 원화와 추가 다중 프레임은 아직 완료되지 않았습니다.
- **v1.4 전투/첫 화면 품질 패치 (2026-11-03):** 영웅 4종 각각의 무기 소켓 (fox 새총 / bear 대포 / rabbit 분열 발사기 / cat 지팡이) 위치를 정의하고 모험 발사·탄도 예측에서 동일한 좌표를 사용. AI 결투는 대포 총구 좌표 유지. 피해 숫자는 실제 맞은 몬스터의 물리 좌표 또는 결투 캐릭터 좌표에 붙어 이동하고, 일반·폭발·관통·격파 색을 구분. 발사체는 SVG 없이 Canvas 2D의 영웅별 목재탄·금속 포탄·날개 분열탄·기류 마법탄으로 묘사를 분리하고, 발사 섬광·영웅별 공격 반동·초단기 충격 정지를 강화함. 여우 탄도 보정 스킬을 사용한 유도탄에는 청록빛 링과 충격력 8% 보너스 부여. 첫 화면은 기존 비트맵 게임 원화 아이콘을 재활용하면서 두꺼운 경계·불투명한 카드 대신 숲 배경과 일체화된 반투명 소재와 명암 분리로 개편, 기존 화면 높이 자동 압축 규칙 유지. 현재 Matter.js 0.20.0 기반 전체 스모크 테스트 및 별도 무기 소켓·이동 대상 데미지 숫자 추적 테스트는 통과함. 단, **실제 안드로이드 세로/가로 시각 검수, GitHub Pages 최신 배포 확인, 캐릭터별 새로운 독립 공격 프레임 원화, 결투 전용 영웅 무기 분리 원화는 아직 미완료**이며 완료로 보고하지 않음. 원본 저장키·스테이지·기존 타 게임은 변경하지 않음.
