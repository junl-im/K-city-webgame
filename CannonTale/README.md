# 캐논테일 (CannonTale) — 웹 플레이어블 v4.2

**게임 이름은 가제이며, 최종 확정 전에도 저장 데이터와 주소를 보존하기 위해 개발용 폴더명 `CannonTale/`을 고정합니다.**

《캐논테일》은 두 종류의 포물선 놀이를 동등한 비중으로 묶은 2D HTML5 게임입니다.

- **모험 포격:** 직접 조준해 나무와 돌 요새를 무너뜨리는 물리 퍼즐. 4개 지역 지도와 지역별 바람, 최종 보스.
- **포격 결투:** 각도·파워·바람을 읽으며 AI와 번갈아 싸우는 탄약·판수 무제한 HP 데스매치. 쉬움/보통/어려움.
- **영웅 4명:** 여우 탄도 보정, 곰 관통, 토끼 오중 분열, 고양이 바람 전환.
- **입력:** 모바일과 PC 터치/포인터, 터치 영역을 넓힌 조준 슬라이더, 스페이스 발사, Q 특수기, 게임 내 조작법.
- **v4.2 전장 전체보기·데스매치·특수기 안내 (2026-11-06):** 모바일 세로 전체보기에서 원화의 하늘 맨 위 2픽셀을 수백 픽셀 높이로 늘려 생기던 세로 줄무늬를 제거했습니다. 실제 풍경의 넓은 구간을 부드럽게 반사해 빈 상단을 연결하며 원본 장면 영역은 그대로 보존합니다. 결투는 탄약·라운드 제한 없는 HP 0 데스매치로 명시하고, 기존 화면 하단의 '우리 팀 내구도/상대 내구도' 문구를 제거했습니다. 대신 두 영웅의 머리 위에 아군·상대 이름, 숫자 HP, 진영별 색상 게이지가 들어간 나무·금빛 미니 HUD를 표시합니다. 영웅 위치와 화면 크기를 따라 움직이며 모바일 전체보기에서도 좌우 잘림을 제한합니다. 여우·토끼의 발사 후 비행 중 사용, 곰·고양이의 발사 전 사용 조건 때문에 특수기가 회색일 때도 클릭할 수 있으며, 누르면 사용할 수 없는 이유를 전장 알림으로 표시하고 사용 횟수는 차감하지 않습니다. 모험 포격의 지역별 탄약 제한과 기존 포물선 조준 카메라는 유지합니다. 자동 회귀 테스트를 확장했고 Android 실제 기기 검수는 아직 남아 있습니다.
- **v4.1.1 조준점 추적 카메라 복구 (2026-11-06):** 충전 중 월드를 축소하던 카메라 효과를 전면 해제하고 기존 조준점·예상 착탄 위치를 따라 이동하는 화면으로 되돌렸습니다. 충전 파워에 맞춘 탄도 갱신은 유지하되, 전체 점선과 착탄 표식을 처음 방식으로 표시합니다. 카메라의 이동 보간을 느리게 조정하고 한 프레임당 이동량을 제한해 급격한 화면 전환을 완화했습니다. v4.1의 넓어진 캐릭터 정보판과 문구 오른쪽 이동은 유지합니다. 자동 회귀 테스트와 모바일 크기 시뮬레이션으로 줌 고정·이동·충전 취소·발사를 검증했으며 실기기 육안 검수는 남아 있습니다.
- **v4.1 캐릭터 정보판 문구 위치·충전 카메라 개선 (2026-11-06):** 그림 메달 바로 옆으로 붙던 정보판 문구의 시작점을 데스크톱·세로 모바일·짧은 가로 화면에서 각각 오른쪽으로 옮겼습니다. 충전 중 조준 예측에 이전 슬라이더 파워가 사용되던 오류를 수정하고, 매 프레임 현재 충전 파워로 탄도·표적·조준 궤적을 다시 계산합니다. 카메라는 발사 캐릭터를 왼쪽 기준으로 두고 실제 예측 사거리만큼 부드럽게 넓어집니다. 조준점이 오른쪽 안전 영역을 넘어갈 때에만 소폭 이동하며, 캐릭터를 화면 밖으로 버리지 않습니다. 자동 테스트에서 세로 360×640과 좁은 가로 화면의 표적 가시성, 카메라 복귀, 충전 해제·취소 동작을 검증합니다. 기기 실사용 터치 검수는 별도로 남아 있습니다.
- **v3.8 착탄/승리 배치 (2026-11-06):** 비최종 착탄 검토는 모험 1.85초·결투 1.65초, 최종 착탄은 2.05초로 짧게 유지합니다. 승리 결과의 3개 원화 메달과 한국어 설명이 세로/가로 화면에서 각각의 종이 영역에 놓이도록 보정했습니다.
- **v3.9 알림 투명도·상단 이동·한글 안전 영역 (2026-11-06):** 전투 시작 안내를 지면에서 상단 하늘 쪽으로 옮겨 폭을 440px 이내로 줄이고, 일러스트 배경만 55% 불투명도로 표시합니다. 착탄 결과판은 위쪽에 작은 폭으로 표시하고 원화 배경 불투명도를 48%로 조정합니다. 실제 글자는 불투명도를 낮추지 않으며, 좁은 화면에서 결과 버튼과 지역 선택 긴 문구를 2줄 이내로 자동 줄바꿈합니다. 독립 그림·물리·세이브 키·다른 게임 경로는 유지합니다. 정적 레이아웃 검증과 Matter.js 스모크 테스트를 적용하며, 안드로이드 실기기 육안 검수는 별도 과제입니다.
- **v4.0 영웅 정보판 확장·충전 시네마틱 카메라 (2026-11-06):** 첫 화면의 여우·곰·토끼·고양이 정보판을 넓히고 원화 장식과 실제 이름/무기/특수기 문구의 안전 영역을 분리했습니다. 문구가 길면 글씨를 잘라내지 않고 줄바꿈하며, 세로·가로 화면의 높이와 폰트를 따로 조정합니다. 전투 중 발사 버튼을 길게 누르면 실제 충전 파워와 예측 착탄 거리만큼 Canvas 카메라가 완만하게 줌아웃하되 발사 영웅을 화면 왼쪽에 유지합니다. 궤적 점선은 파워 비율에 따라 출발점에서 앞으로 단계적으로 길어지고 끝에 빛나는 표시가 따라갑니다. 발사·취소·화면 회전 후에는 부드럽게 원래 줌으로 돌아가며, 고정 지면과 배경 원화의 위아래 빈 공간을 보정했습니다. 새 외부 카메라 엔진·SVG·저장키 변경은 없습니다. Matter.js 자동 테스트로 세로 360×640, 가로 및 좁은 화면, 길게 누르기·해제·취소·재발사·결투를 검증했으며 실제 Android/Windows 기기의 육안 확인은 별도로 필요합니다.

- **v1.1.1 몬스터 동작 후속 패치:** 도토리 수호병·이끼 바위거인·바람의 정령·강철 화염대장 4종 각각의 대기·공격·피격·쓰러짐 투명 배경 원화 총 16포즈를 추가했습니다. 피해를 받으면 공격 동작을 끊고 피격 동작으로 전환하며, 격파 시 쓰러진 모습을 잠시 유지합니다. 모험의 몬스터 공격 포즈는 현재 위협 연출이며 플레이어에게 직접 피해를 주는 기술은 아닙니다. 목재·석재·철재는 균열 단계에서 재료별 파편·섬광·충격파를 추가하고, 지면에 떨어진 파편을 현장에 남겨 포격 결과를 확인할 수 있습니다.
- **v1.2 포즈 전환 보정:** 기존 4종 × 4포즈 시트를 그대로 사용하면서 등장 착지 반동·공격 전방 기울임·대기 호흡·사망 회전과 눌림을 시간 기반으로 보정했습니다. 별도의 신규 다중 프레임 원화가 완성된 것은 아니며 실제 안드로이드 세로·가로 실기기 검수는 미완료입니다.

GitHub Actions CI 실행 결과 및 안드로이드 실기기 시각 검수는 별도로 확인되지 않았습니다. SVG 자산은 추가하지 않았습니다.
