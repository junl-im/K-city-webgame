# 캐논테일 (CannonTale) — 웹 플레이어블 v1.1.1

**게임 이름은 가제이며, 최종 확정 전에도 저장 데이터와 주소를 보존하기 위해 개발용 폴더명 `CannonTale/`을 고정합니다.**

《캐논테일》은 두 종류의 포물선 놀이를 동등한 비중으로 묶은 2D HTML5 게임입니다.

- **모험 포격:** 직접 조준해 나무와 돌 요새를 무너뜨리는 물리 퍼즐. 4개 지역 지도와 지역별 바람, 최종 보스.
- **포격 결투:** 각도·파워·바람을 읽으며 AI와 번갈아 벌이는 턴제 결투. 쉬움/보통/어려움.
- **영웅 4명:** 여우 탄도 보정, 곰 관통, 토끼 오중 분열, 고양이 바람 전환.
- **입력:** 모바일과 PC 터치/포인터, 터치 영역을 넓힌 조준 슬라이더, 스페이스 발사, Q 특수기, 게임 내 조작법.
- **v0.8 시각 개선:** 지역에 따라 변하는 적 4종의 신규 원화, 피격 반응, 캔버스 예상 궤적 및 구조물·적·지면 충돌점 표시, 탄종별 시각 구분.
- **v0.9 손맛 개선:** 몬스터 대기·피격·사망 전환, 나무·돌·철 구조물의 3단계 수작업 캔버스 재질·균열 묘사, 포신 반동·화염·충격파·먼지, 무기별 결투 AI 전술, 모바일 세로·가로 화면별 조작 패널 배치.
- **v1.0 원화 연결:** 업로드한 그림을 WebP로 경량화하여 목재·석재·철재를 손상 3단계(멀쩡함/균열/심각 파손)별 실제 원화로 교체. 체력 임계점마다 파편·불꽃이 추가로 발생합니다. 4지역 지도와 첫 등장 연출에는 도토리 수호병·이끼 바위거인·바람의 정령·강철 화염대장의 신규 일러스트가 등장합니다. 새 몬스터 시트는 배경이 포함되어 있어 전투 중에는 기존 투명 원화와 물리 충돌 처리를 유지하며, 추후 배경 분리 후 전투 스프라이트로 교체합니다.
- **v1.1 포격 결과 확인:** 모든 탄착 후 착탄 지점을 카메라가 유지하고, 구조물 피해·몬스터 격파·결투 HP 변화를 보여 주는 결과 리본을 표시합니다. 모험은 사용자가 `다음 발사` 또는 `승리/도전 결과 보기`를 누르기 전까지 자동으로 발사점에 복귀하지 않으며, 결투는 결과를 3.5초 보여준 뒤 자동으로 다음 턴을 진행합니다. 최종 결과창에서는 `파괴 현장 보기`로 전장 관찰 후 다시 결과창으로 돌아올 수 있습니다.
- **v1.1 인터페이스 원화:** 독립 제작한 3×3 PNG 아이콘 아틀라스로 모드 카드·포탄 선택·발사·특수기·망원경·지역 지도를 갱신했습니다. SVG·이모지·외부 폰트는 사용하지 않습니다. 모바일 세로·가로의 버튼 비율과 여백을 따로 조정했습니다.
- **v1.1.1 몬스터 동작 후속 패치:** 도토리 수호병·이끼 바위거인·바람의 정령·강철 화염대장 4종 각각의 대기·공격·피격·쓰러짐 투명 배경 원화 총 16포즈를 추가했습니다. 피해를 받으면 공격 동작을 끊고 피격 동작으로 전환하며, 격파 시 쓰러진 모습을 잠시 유지합니다. 모험의 몬스터 공격 포즈는 현재 위협 연출이며 플레이어에게 직접 피해를 주는 기술은 아닙니다. 목재·석재·철재는 균열 단계에서 재료별 파편·섬광·충격파를 추가하고, 지면에 떨어진 파편을 현장에 남겨 포격 결과를 확인할 수 있습니다.
- **미리보기 주의:** 예상 타격점은 발사 순간의 정적 위치 기준입니다. 발사 후 구조물이 움직이거나 특수기를 쓰면 실제 충돌이 달라질 수 있습니다.
- **저장:** 최고 등급과 승리 기록은 브라우저 `localStorage`에 유지합니다.

## 실행

[GitHub Pages에서 플레이](https://junl-im.github.io/K-city-webgame/CannonTale/) — Pages 워크플로가 배포된 뒤 이용할 수 있습니다.

이 폴더를 내려받아 `index.html`을 열어도 게임을 시작할 수 있습니다. 아래 파일들을 `index.html`과 같은 폴더에 유지해야 합니다.

1. `matter.min.js` — MIT 라이선스 물리 엔진
2. 여우/곰, 토끼/고양이, 버튼/연출, 4지역 배경의 네 WebP 원화와 기존 적 캐릭터 투명 PNG 아틀라스
3. `Artillery_Material_Damage_Atlas_v1_0.webp` — 나무/돌/철 × 3단계 파괴 원화
4. `Artillery_Forest_Enemy_Atlas_v1_0.webp` — 지역 지도·전투 진입의 네 신규 적 일러스트
5. `Artillery_Illustrated_UI_v1_1.png` — SVG 없는 9종 수작업풍 포격 버튼 원화
6. `Artillery_Combat_Poses_v1_2.png` — 몬스터 4종 × 4종 행동(대기/위협 공격/피격/사망)의 투명 PNG 전투용 포즈 시트

## 개발과 검증

`node artillery_smoke_test.cjs` — 구조물 물리 안정성·철재 구간, 폭발 애니메이션, 포격, 턴 교대, 네 영웅 특수기, 저장, 지역 선택, 모바일 캔버스, 브라우저 뒤로가기 모의 검증.

CI 물리·입력·저장 스모크 테스트와 GitHub Pages 배포 검증을 수행합니다. 화면 너비 390px 캔버스 크기, 원화 준비 상태·몹 등장 배너 자동 종료·착탄 결과 유지·명시적 다음 발사 확인·SVG 금지 검증을 포함합니다. 실제 안드로이드 휴대폰의 터치·회전·브라우저 안전 영역은 기기별 수동 QA가 추가로 필요합니다. 4종 × 4포즈는 전투 상태별 키 포즈로 연결된 상태이며, 각 상태 내부의 독립적인 다중 프레임 스프라이트 제작과 실기기 확인은 차기 과제입니다.
