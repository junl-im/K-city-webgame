# 곰같은여우 AI MUSIC RADIO

55곡(8집 35곡, 9집 20곡)으로 시작하는 24시간 라디오 프로토타입.

- GitHub에는 소스와 편성 정보만 저장합니다. MP3/WAV는 업로드하지 않습니다.
- 공개 사이트는 음악 재생을 활성화하기 전에 Cloudflare R2 또는 동등한 음원 스토리지를 연결해야 합니다.
- 로컬 테스트는 이전에 제공된 AI-Music-Radio-MVP-v2.zip을 이용하세요.
- 모든 공개 표시 이름은 '곰같은여우'만 사용합니다.
- DistroKid 배포 계약, AI 생성 도구 라이선스, 커버/샘플 및 국내 음악서비스 신고 여부를 확인한 뒤 공개 송출합니다.

## 상태
GitHub 기반 정적 UI / 배포 준비 단계. 음원 송출 미연결.
