## 제작 원칙

- 고정: SVG 파일·inline SVG·SVG 배경·SVG 아이콘·SVG 데이터 URI 금지.
- 게임 UI의 모든 신규 시각 원화는 자체 제작 PNG만 사용하며, 원화는 GitHub LieRoom/dist/assets/에서 상대 경로로 제공.
- AI 이미지 생성으로 제작된 원본 PNG는 제3자 라이선스 오픈소스를 임의로 복제한 것이 아님. 외부 라이브러리도 이번 증분에는 추가하지 않음.
- 속도·접근성: 기능성 텍스트/초점 윤곽은 HTML/CSS로 유지. 텍스트를 이미지에 태우지 않고 버튼마다 접근 가능한 이름을 보존.

## LR-007 신규 인물 원화 (2026-10-30)

- 파일: `dist/assets/lie-room-next-cast-atlas-v1.png` (1254×1254, 3×3, 자체 제작, PNG).
- 열 고정: D 최강현(은발·안경·와인색 조끼의 50대 남성 관장), E 서라온(브라운/플래티넘 묶은 머리·복원 작업복의 30대 여성), F 차민혁(짧은 곱슬머리·인디고 코트의 30대 남성 기자).
- 행 고정: 기본/신뢰/경계. 각 열에서 같은 인물·의상·촬영 각도를 유지하여 심리 표정 전환에 재활용.
- 기존 `lie-room-expression-atlas-v1.png`의 인물 A/B/C 원화는 원형 유지. 이번 아틀라스는 신규 D/E/F 전용.
- 새 인물은 첫 사건 용의자에 혼합하지 않고 인물 도감에서 **다음 사건 준비**로만 표시. 사건 원고와 증거가 준비된 이후에 사건 시스템에 편입.
- 실제 아틀라스는 GitHub Pages 정적 자산이며 SVG 사용 없음.

## 증거-아이콘 매핑 (화면 장식일 뿐 범인 판정에 영향 없음)

- E01 출입 기록 → 출입증 (0%, 0%)
- E02 도난 신고서 → 사건 서류 (100%, 0%)
- E03 복도 목격 메모 → 손글씨 메모 (50%, 0%)
- E04 출입증 전달 사진 → 폴라로이드 (100%, 50%)
- E05 경보 해제 로그 → 경보 키패드 (50%, 50%)
- E06 뒷문 CCTV → 감시 카메라 (0%, 50%)
- E07 출고 명세서 → 봉인 상자 (0%, 100%)

제작 아틀라스의 색과 장식은 개별 버튼을 구분하기 위한 원화이며, 심리 신호 자체는 독립 물증으로 간주하지 않음.

## 생성 이미지 메타데이터 정리

신규 PNG 3종은 전달용 제작 메타데이터(caBX)를 제거해 순수 PNG 픽셀 스트림만 보존한다. 원화의 실제 화면은 동일하며 SVG 리소스가 포함되지 않는다.

## LR-010 · 2번 사건 연결 (2026-10-30)

- `lie-room-next-cast-atlas-v1.png`의 최강현(D)·서라온(E)·차민혁(F) 기본/신뢰/경계 9컷을 2번 사건 용의자 선택·중앙 심문 초상에 실제 적용함.
- 1번 사건의 A/B/C 표정 원화는 그대로 유지하며, 2번 사건에서도 인물 도감에 여섯 캐릭터를 열람 가능.
- 사건별 논리 및 세이브 격리와 독립적으로 표정과 설명이 변경되며, 누아르 스타일 PNG를 사용하고 SVG는 사용하지 않음.
- 2번 사건의 증거 소품은 우선 기존 공통 수사 도구 원화를 재사용하고, 향후 사건 전용 카드·저장 매체·녹음기 원화를 개별 보강할 예정.
