# 《거짓말의 방》 — 첫 심문실 프로토타입

곰같은여우의 AI 놀이터에 연계할 무료 웹 심리 추리 게임. 현재 `LR-001 사라진 은빛 가면` 사건 한 건을 처음부터 결말까지 플레이할 수 있다.

## 실행

- 웹 정적 파일: `dist/index.html`, `dist/style.css`, `dist/app.mjs`, `dist/core.mjs`.
- ES module이므로 로컬에서는 HTTP 정적 서버로 서빙해야 한다. GitHub Pages에서는 별도 패키지 설치 없이 실행된다.
- 테스트: `node LieRoom/tests/smoke.mjs` (저장소 루트 기준).
- 모든 경로는 상대 경로이므로 `/K-city-webgame/LieRoom/` 하위에 배치할 수 있다.

## LR-004 원화·연출

- 독립적으로 제작한 PNG 심문 원화 `dist/assets/lie-room-expression-atlas-v1.png`의 3×3 표정 아틀라스: 인물 A/B/C, 기본·신뢰·경계.
- 심리 상태에 따라 해당 인물의 표정이 자동으로 바뀐다. SVG·외부 이미지 API가 필요 없다.
- 효과음은 초기값 **끔**이며, 사용자가 버튼을 눌러 켜면 Web Audio 기반 짧은 신호음만 사용한다. 브라우저 미지원 시 소리 없이 계속 동작한다.


## LR-005 · 전체 UI 원화 개편 (2026-10-30)

- 홈과 사건 도입 화면의 밤 미술관 배경 `dist/assets/lie-room-museum-night-v1.png` (자체 제작 PNG).
- 실제 수사 증거와 보관소 모드 카드의 전용 소품 원화 `dist/assets/lie-room-evidence-icons-v1.png` (3×3 아틀라스, 실물 PNG).
- 기본·보조·공감·압박 행동을 서로 구분하는 4종의 금속·가죽·녹청·적갈색 패널 원화 `dist/assets/lie-room-material-buttons-v1.png` (2×2 아틀라스).
- 인물 선택 아이콘도 기존 표정 원화를 직접 재사용하며, 기존 질문·대질·저장 로직을 유지.
- SVG / 외부 호스팅 리소스 / 유료 API 없이 모든 이미지가 `LieRoom/dist/assets` 아래에 존재. 각 자산은 실제 게임 화면에 연결되어 자동 검사 대상임.

## LR-006 · 수사 시간선과 기록 보호 (2026-10-30)

- 심문 화면과 최종 판정 화면에서 **수사 시간선**을 열어 확보한 증거만 발생 시각순으로 비교.
- 시간선의 증거는 기존 수사 소품 PNG 원화를 연결하며, 항목을 누르면 원본 증거의 출처·내용 확인 가능.
- 아직 찾지 못한 증거는 노출하지 않으며, 대질한 기록은 대질 완료로 표기. 범인의 정체를 사전에 암시하지 않음.
- 진행 기록이 있을 때 **새 사건 시작**을 누르면 기존 수사를 유지할지 초기화할지 확인. 저장 데이터 형식과 판정 엔진은 그대로 유지.
- 테스트에서 시간순 정렬·증거 노출 금지·대질 표기·버튼 연결을 회귀 점검.

## LR-007 · 인물 아틀라스 추가와 등장인물 도감 (2026-10-30)

- 첫 사건의 기존 3명×3표정 원화는 유지하며, **다음 사건용 신규 3명×3표정** 일러스트 아틀라스 PNG 추가.
- 추가 인물: 최강현(은발 미술관 관장), 서라온(복원사), 차민혁(탐사 기자). 각자의 헤어·연령·복장·직업·표정 특징을 구분함.
- 메인 '인물 도감 · 6명 보기'에서 6명의 기본/신뢰/경계 표정을 실제 아틀라스에서 확인 가능.
- 다음 사건 인물은 **미리보기 전용**, 첫 사건의 용의자 수·증거·범인 판정·기존 세이브 불변.
- PNG 아틀라스는 `dist/assets/lie-room-next-cast-atlas-v1.png`. 원본 레퍼런스의 누아르 그림체를 바탕으로 별도 제작.

## LR-008 · GitHub Pages 정적 리소스 캐시 갱신 (2026-10-30)

- GitHub Pages 배포는 최신 커밋이지만 사용 중인 브라우저에서 구버전 JS/CSS가 남는 상황을 확인하여 파일 참조에 `?v=lr008` 버전을 고정.
- `index.html`의 CSS/앱 모듈과 앱 모듈의 핵심 엔진 import를 동일한 버전 쿼리로 통일해 업데이트 시 최신 파일을 요청하도록 수정.
- 기존 저장 키, 인물 아틀라스, 판정 로직, 독립 경로는 변경하지 않음.
- 추후 CSS/JS를 수정하는 배포에서는 `?v=` 값도 함께 올려 캐시가 재사용되지 않도록 관리.

## LR-009 · 인물 이름표·UI 마감 (2026-10-30)

- 6인 도감의 카드가 높이 압축되어 이름·직업이 잘리던 레이아웃을 수정. 인물 사진 아래쪽에 어두운 그라데이션 이름표를 얹어 선명하게 표시.
- 모바일에서는 카드 설명을 간소화하고 이름·직업을 우선 표시.
- 게임 내 우클릭 메뉴와 기본 이미지 드래그를 차단하고, 내부 스크롤바를 누아르 금속색으로 통일.
- JS/CSS 참조 버전을 `lr009`로 갱신해 새 배포에서 캐시를 새로 요청.

## 구현된 기능

- 심문할 인물 3명 선택, 총 7개 질문과 일관된 증언.
- **LR-003 심리 접근 6종:** 용의자별 공감·압박 선택, 선택 순서에 따른 신뢰·긴장 변화, 답변 태도와 심리 신호 기록. 심리 신호만으로 유죄를 판정하지 않으며 증거는 계속 확보 가능.
- **LR-002 증거 대질 5건:** 질문 → 증거 발견 → 해당 인물에게 증거 제시 → 심리적 모순 반응 확인. 대질 기록·해석은 심문 기록에 보관하며 사건 해결에는 강제하지 않는다.
- 확보 증거 7개(초기 2개, 심문 후 5개), 증거 출처·시간·모순 설명.
- 최대 3개 증거 선택 및 범인 지목; 정확/근거 부족/오답 3가지 결과.
- 거짓말쟁이와 진범을 구분하는 확정 사건 진실.
- `localStorage` 이어하기 및 다른 탭 변경 반영, 저장 실패 알림. 기존 v1 저장 데이터는 대질 기록이 없어도 정상 복구.
- 모바일·PC 반응형, 내부 컨텐츠 스크롤, 키보드 Escape 모달 닫기, 움직임 축소 선호 처리.
- 외부 라이브러리/서버/API/로그인 불필요. SVG 자산·파일·데이터 URI 사용하지 않음.

## 아직 구현하지 않은 것

- 수상한 방문객, 사라진 메시지, 60초 미스터리, 배신자 게임은 예고 카드만 표시.
- 기존 기획 원화의 고해상도 캐릭터 스프라이트 및 증거 이미지 결합.
- 글로벌 랭킹/멀티플레이/정교한 AI 대화, 사건 다양화.
- 실제 휴대전화·PC 브라우저에서의 수동 레이아웃 점검.
- 사건 2편 이후 및 심문 난이도별 힌트, 실제 기기 별 레이아웃/오디오 접근성 검수.

## 저장소 통합 원칙

`K-city-webgame`의 기존 `MagicGarden`, `SixtySecondPlayground`, `FlowerMatgo`, `PhysicsPopbook` 소스를 수정하지 않는다. GitHub Pages 워크플로에 `LieRoom/dist/`를 별도 경로로 복사하는 단계만 추가해야 게시된다.
