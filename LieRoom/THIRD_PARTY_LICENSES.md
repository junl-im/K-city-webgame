# 외부 자산 및 라이선스 원장

현재 프로토타입은 외부 코드/시각 자산을 다운로드·포함하지 않았습니다. 브라우저 기본 기능과 자체 작성 코드 및 CSS만 사용합니다.

향후 사용 후보(포함 전 개별 라이선스 재확인):

| 후보 | 용도 | 공식 주소 | 확인할 사항 |
|---|---|---|---|
| ink/inkjs | 대화 분기 | https://github.com/inkle/inkjs | MIT 및 포함되는 종속물 |
| Kenney Interface Sounds | UI 효과음 | https://kenney.nl/assets/interface-sounds | CC0, 사용한 개별 파일 |
| Kenney UI Pack Adventure | PNG UI | https://kenney.nl/assets/ui-pack-adventure | CC0, SVG 제외 |
| Pretendard | 한글 UI | https://github.com/orioncactus/pretendard | OFL, 포함 시 라이선스 고지 |

타 게임의 고유 이미지, 사운드, 스토리, 상표를 무단 복제하지 않습니다.
