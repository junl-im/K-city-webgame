# 라니맞고 음성·효과음

라니맞고의 대사와 상황 연결은 이 게임을 위해 구성했습니다. `public/assets/rani-voice-v3/`의 짧은 MP3는 소리온 로컬 합성 경로로 제작한 게임 전용 음원입니다. 실제 성우 녹음이나 독점적으로 훈련한 캐릭터 목소리는 아닙니다.

- 합성 엔진: [Supertone Supertonic 3](https://huggingface.co/supertone-oss-archive/supertonic-3), 모델 리비전 `aafc6e32416a594460b32413efc49d7fe4ce6d46`, F1 프리셋(소리온 별하 경로), 한국어, 합성 속도 1.13. 앞뒤 무음 정리 후 재생속도 1.15배로 밝고 빠르게 편집했습니다.
- 모델 라이선스: [BigScience Open RAIL-M](https://huggingface.co/supertone-oss-archive/supertonic-3/blob/aafc6e32416a594460b32413efc49d7fe4ce6d46/LICENSE). 모델 자체는 게임에 포함하지 않고 합성 결과만 배포합니다.
- 플레이어는 음성 모델을 내려받지 않습니다. 클립은 필요한 순간에 재생하고, 설정에서 AI 합성 음성과 효과음을 독립적으로 조절할 수 있습니다.
- 생성된 음원은 고유 대사이지만 기반 F1 음색은 공개 프리셋이므로 독점 캐릭터 성우라고 표시하지 않습니다.

상황 연결은 `src/voiceEvents.js`에서 엔진의 실제 결과를 기준으로 결정합니다. 첫뻑은 일반 뻑과 중복 선언하지 않고, 피 이동은 실제 이동한 카드와 플레이어 방향을 확인합니다. 고 횟수, 흔들기·폭탄, 쪽·따닥·싹쓸이, 보너스, 미션, 조합, 총통, 멍따·고박과 결과를 지원합니다. 효과음은 기존 `cardSoundDesign.js`의 로컬 Web Audio 합성음을 사용합니다. 음성은 한 번에 하나씩 재생하고 오래된 대기 음성은 버립니다. 판이 끝나면 재생 중인 음성은 마저 들려주고 지난 대기 음성 대신 정산 음성을 우선합니다.

음성 설정은 첫 화면의 **소리 설정**, 게임 중에는 **도움말 → 소리 설정**에서 접근합니다. 기존에 효과음을 꺼 둔 이용자는 음성도 기본적으로 꺼진 상태로 시작합니다. 브라우저 음성 재생은 사용자의 첫 조작 이후에 시작하며, 기기·브라우저에서 자동 재생을 차단하면 게임은 무음으로 계속 동작합니다.

## 상황별 소리 점검표

| 상황 | 음성 | 효과음 |
| --- | --- | --- |
| 시작과 선 결정 | 시작, 실제 선공자 안내 | 시작음, 패 섞기·뒤집기 |
| 패를 놓고 짝을 맞춤 | 특수 상황일 때 해당 대사 | 착지, 짝, 뒤집기, 획득 |
| 쪽·따닥·뻑·폭탄·싹쓸이 | 각 상황 대사 | 상황별 타격음 |
| 피가 실제로 이동 | 내 쪽 이동과 상대 쪽 이동을 구분 | 관련 패 획득음 |
| 보너스패 | 피 이동이 없을 때 보너스 대사 | 보너스 효과음 |
| 미션 완료 | 미션 성공 | 미션 효과음 |
| 청단·홍단·초단·고도리 | 완성된 조합 대사 | 획득음 |
| 고·스톱 | 실제 확정된 고 횟수 또는 스톱 | 고·스톱 효과음 |
| 판 종료 | 박·멍따 및 승리·패배, 무승부 시 나가리 | 결과 효과음 |

자동 스톱으로 복구된 마지막 패 상황은 고가 아닌 스톱으로 안내합니다. 사용자의 취향에 맞는지와 합성 음성의 발음은 실제 청취를 통해 별도로 확인해야 합니다.
