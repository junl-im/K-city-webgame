# 라니맞고 음성·효과음

라니맞고의 대사와 상황 연결은 이 게임을 위해 구성했습니다. `public/assets/rani-voice-v4/`의 짧은 MP3는 소리온 로컬 합성 음성을 밝은 캐릭터풍으로 가공한 게임 전용 음원입니다. 실제 성우 녹음이나 독점적으로 훈련한 캐릭터 목소리는 아닙니다.

- 합성 엔진: [Supertone Supertonic 3](https://huggingface.co/supertone-oss-archive/supertonic-3), 모델 리비전 `aafc6e32416a594460b32413efc49d7fe4ce6d46`, F1 프리셋(소리온 별하 경로), 한국어. 기존 대사에서 앞뒤 무음을 정리하고 v4에서 음높이와 음색을 밝게 가공했습니다. 시작·선공·아쉬운 대사는 길이가 지나치게 줄지 않도록 속도를 적게 높였습니다.
- 모델 라이선스: [BigScience Open RAIL-M](https://huggingface.co/supertone-oss-archive/supertonic-3/blob/aafc6e32416a594460b32413efc49d7fe4ce6d46/LICENSE). 모델 자체는 게임에 포함하지 않고 합성 결과만 배포합니다.
- 플레이어는 음성 모델을 내려받지 않습니다. 클립은 필요한 순간에 재생하고, 설정에서 AI 합성 음성과 효과음을 독립적으로 조절할 수 있습니다.
- 생성된 음원은 고유 대사이지만 기반 F1 음색은 공개 프리셋이므로 독점 캐릭터 성우라고 표시하지 않습니다.
- 시작 대사는 '자!', '시작해 보자!', '신나게!'를 따로 합성한 뒤 결합한 `start-v5.mp3`를 사용합니다. 이전 파일을 캐시한 기기도 새 파일을 받습니다.
- 선공, 묻고 더블로, 미션 성공, 승리, 피 이동과 조합 비상 대사도 각각의 어구를 따로 생성해 결합하고 새 파일 이름으로 제공합니다.

상황 연결은 `src/voiceEvents.js`에서 엔진의 실제 결과를 기준으로 결정합니다. 첫뻑은 일반 뻑과 중복 선언하지 않고, 피 이동은 실제 이동한 카드와 플레이어 방향을 확인합니다. 고 횟수, 흔들기·폭탄, 쪽·따닥·싹쓸이, 보너스, 미션, 조합, 총통, 멍따·고박과 결과를 지원합니다. 효과음은 기존 `cardSoundDesign.js`의 로컬 Web Audio 합성음을 사용합니다. 음성은 한 번에 하나씩 재생하고, 재생 중 새 상황이 이어지면 가장 최근 대기 음성 하나만 남기며 늦어진 대사는 버립니다. 판이 끝나면 재생 중인 음성은 마저 들려주고 지난 대기 음성 대신 최신 정산 음성을 우선합니다.

음성 설정은 첫 화면의 **소리 설정**, 게임 중에는 **도움말 → 소리 설정**에서 접근합니다. 기존에 효과음을 꺼 둔 이용자는 음성도 기본적으로 꺼진 상태로 시작합니다. 브라우저 음성 재생은 사용자의 첫 조작 이후에 시작하며, 기기·브라우저에서 자동 재생을 차단하면 게임은 무음으로 계속 동작합니다.

## 상황별 소리 점검표

| 상황 | 음성 | 효과음 |
| --- | --- | --- |
| 시작과 선 결정 | 시작, 실제 선공자 안내 | 시작음, 패 섞기·뒤집기 |
| 패를 놓고 짝을 맞춤 | 특수 상황일 때 해당 대사 | 착지, 짝, 뒤집기, 획득 |
| 낼 수 있는 짝패를 두고 바닥에 없는 패를 냄 | “앗, 먹을 패가 있었네!” | 짧은 알림음 |
| 낼 수 있는 짝패가 없어서 바닥에 없는 패를 냄 | “먹을 게 없네?” | 짧은 알림음 |
| 쪽·따닥·뻑·폭탄·싹쓸이 | 각 상황 대사 | 상황별 타격음 |
| 피가 실제로 이동 | 내 쪽은 “내놔!”, 상대 쪽은 “으윽, 가져가…” | 관련 패 획득음 |
| 보너스패 | 보너스 자체는 말하지 않으며 실제 피 이동이 있으면 방향에 맞춰 반응 | 보너스 효과음 |
| 미션 완료 | 미션 성공 | 미션 효과음 |
| 청단·홍단·초단·고도리 | 완성된 조합 대사 | 획득음 |
| 청단·홍단·초단·고도리 비상 | 상대가 해당 패 두 장을 모으고 내가 해당 패를 갖고 있지 않으면 비상 안내 | 획득음 |
| 고·스톱 | 실제 확정된 고 횟수 또는 스톱 | 고·스톱 효과음 |
| 판 종료 | 박·멍따 및 승리·패배, 무승부 시 나가리 | 결과 효과음 |

자동 스톱으로 복구된 마지막 패 상황은 고가 아닌 스톱으로 안내합니다. 사용자의 취향에 맞는지와 합성 음성의 발음은 실제 청취를 통해 별도로 확인해야 합니다.
