# 꽃맞고 v17 — 손그림 한지 UI 재정비

## 수정 이유

현준님 피드백: 최근 화면이 촌스럽고 SVG처럼 보이며 버튼들이 지나치게 도드라진다. 게임의 귀여운 개성은 유지하되 전체 UI를 손으로 채색한 일러스트 분위기로 통일한다.

## 적용

- `public/assets/flower-handpainted-button-v17.webp`: 실제 수채화로 그린 꽃 장식 목재 명패. 홈 메인 버튼, 상대 선택 시작, 주요 팝업 버튼에 사용. 빛나거나 숨 쉬는 확대 애니메이션은 제거.
- `public/assets/flower-handpainted-paper-v17.webp`: 한지·수채화 종이 질감. 카드판 외부의 안내 패널, 캐릭터 선택, 획득한 패 정보, 대화창, 보조 버튼에 사용. CSS 벡터 유사 장식 대신 실제 비트맵 원화를 사용.
- 기존의 사탕 같은 그라데이션, 두툼한 플라스틱 테두리, 진한 그림자, 발광 등은 차분한 녹색·목재·분홍색과 얕은 그림자로 변경.
- 첫 화면 타이틀의 과장된 여러 겹 입체 그림자와 굵은 글자 외곽선은 제거. 한지 배경 위의 수묵 서체로 조정.
- 라니팡 분위기의 귀여운 동물 마스코트는 유지. `src/turnPresentation.js`의 패 착지→충돌→더미 뒤집기→획득 순서와 `src/main.js`의 점수 획득 캐릭터 반응도 유지.
- 별도 원본 콘셉트는 `artwork/concepts/flower-handpainted-button-v17.png`, `artwork/concepts/flower-handpainted-paper-v17.png`에 보관.

## 반드시 유지

- **48장 원판** `public/assets/hwatu-strict90-labeled-atlas-v3.webp`는 도트 하나 변경하지 않는다. 색상·문양·광·띠·쌍피 분류 그대로.
- `gomfox-flower-matgo-v01` 게임 기록 및 게임 규칙은 그대로.
- 맞고 플레이 화면과 선택 화면의 모바일 한 화면 레이아웃, 작은 화면 타이머 가독성을 우선.
- 손그림 효과용 추가 SVG는 생성/삽입하지 않는다.

## 검증 상태

- 색상과 카드 식별성: 48장 아틀라스 SHA-256 고정 테스트.
- 손그림 WebP 포맷과 다운로드 용량: 신규 자동 테스트.
- 실제 다양한 모바일 기기에서 터치 영역·스크롤·텍스트 판독: 추가 수동 점검 필요.

## 다음 디자인 참조 확인 대기 (사용자 추가 요청)

- 사용자가 공유한 ChatGPT 제작 시안 `https://chatgpt.com/s/m_6ae180652e208191bb9f995e25a3b78d`를 **화투판·패 자리 UI·화투패 전체의 새로운 기준**으로 지정했다. 이 최신 지시는 위의 '원판 고정'보다 우선한다.
- 현재 외부 링크의 실제 시안 이미지를 도구에서 읽을 수 없어, 임의 추측으로 승인된 화투패 아틀라스를 바꾸지 않았다.
- 정확한 시안 이미지가 확보되면 먼저 새 별도 아틀라스와 판 원화를 제작·비교한 뒤, 48장 순서·분류·효과 연동을 재검증한다. 현재의 v17 손그림 UI 작업은 아직 게시하지 않았다.
