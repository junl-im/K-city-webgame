# 꽃맞고 48장 원패 식별 보호 체크리스트

2026-10-28 사용자 최종 강조: **원본 화투의 구도·색·상징을 최소 95% 유지하고 캐릭터/화풍 변화는 최대 약 5%. 한순간도 어떤 패인지 헷갈려서는 안 된다.**

## 최종 아트 검수

- [ ] 월별 4장의 공통 꽃/가지가 카드의 가장 큰 시각적 식별 단서로 남아 있다.
- [ ] 광 5장은 다른 카드와 즉시 구별 가능하고 `光` 식별 표기가 정확하다.
- [ ] 열끗 9장의 원래 동물·국진 술잔·사슴·제비 등이 가려지지 않았다.
- [ ] 홍단·청단은 각각 세 장 모두 흰색 글자 표시. 초단·비띠는 **글자 없음**. 10장 이외에는 띠가 존재하지 않는다.
- [ ] 쌍피/보너스피가 일반 피와 혼동되지 않는다.
- [ ] 모바일 360px 화면의 손패/먹은 패 크기에서도 월과 타입을 구별할 수 있다.
- [ ] 광/열끗/띠/피 각각 **동물 없는 기본패와 동물 있는 새 패를 1초 안에 동일 카드로 식별**할 수 있다.
- [ ] 각 장의 마스코트/화풍 변경 면적이 5% 수준 이내이며 원래 월별 실루엣·패 구도를 침범하지 않는다.
- [ ] 빨간 띠 6개(홍단 3·초단 3), 파란 띠 3개(청단 3), 비띠 1개 표기가 정확하다.
- [ ] 보너스 쌍피 2장·삼피 1장과 전용 붉은 뒷면이 실제 게임에서 올바른 그림으로 나온다.
- [ ] 모든 카드가 4열×12행 스프라이트의 올바른 좌표에서 출력된다.
- [ ] 카드 인지성 테스트에서 잘못 식별한 시안을 교체한다. 이미지 품질만으로 합격시키지 않는다.
- [ ] PNG/WebP 외 SVG 자산을 사용하지 않는다.
