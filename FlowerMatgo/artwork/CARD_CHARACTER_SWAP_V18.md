# 화투패 캐릭터만 교체하기 — 사용자 원본 보존 지시

## 입력 시안

- 사용자가 다시 업로드한 `2562.png`, `2563.png`: 빨강·검정·흰색 전통 화투패 7~12월, 파란 옷 곰·분홍 옷 여우·초록 옷 고양이가 작은 캐릭터로 들어간 목표 스타일.
- 사용자가 다시 업로드한 `2553.jpg`, `2555.jpg`, `2557.jpg`, `2559.jpg`: 옛 카드의 꽃·동물·띠·쌍피·광 표시를 판독하기 위한 원본 사진.
- 캐릭터 원본: `public/assets/mascots.png`의 갈색 곰·주황 여우·흰 고양이 한복 입은 시그니처 3종.

## 확정된 교체 범위

1. 원본 화투패의 빨간 테두리, 흰 여백, 꽃/가지/잎, 띠와 광의 위치 및 색상, 월별 문양은 그대로 둔다.
2. 기존 카드 안의 다른 캐릭터·사람만 곰·여우·고양이로 바꾼다. 배경 위에 큰 캐릭터를 억지로 올리거나 카드 성격을 바꾸지 않는다.
3. 타깃은 사진처럼 사선으로 보이는 카드 묶음이 아니라 실제 게임에서 사용하는 **정면 48장**이다. 원본 고유 색감과 장수를 유지해야 한다.
4. 카드 앞면 아틀라스는 후보 제작→48장 식별/쌍피 검수→런타임 전환 순서로 별도 이름을 사용한다. 새 아틀라스 확정 전까지 `public/assets/hwatu-strict90-labeled-atlas-v3.webp`를 안전한 실게임 원판으로 유지한다.

## 제작 및 검토 기록

- `concepts/hwatu-character-swap-01-03-sample-v18.png`: 1~3월 원본 사진에서 캐릭터만 바꾸는 보존 테스트. 정면 카드 48장으로 사용할 원본이 아니므로 검수 전 실제 게임에 연결하지 않음.
- `concepts/hwatu-character-swap-04-06-sample-v18.png`: 4~6월 원본 사진 캐릭터 교체 검수용. 붓선·띠 글자까지 완전히 같지는 않으므로 실제 게임에는 미연결.
- `concepts/hwatu-userapproved-months10-12-v18.png`: 사용자가 최종 범위를 좁히기 **전에** 전체 일러스트를 다시 그린 실험. 새로 그린 꽃과 줄기가 원본과 달라져 **반려 후보**로 분류, 실게임 연결 금지.
- `public/assets/flower-game-floor-mat-v18.webp`: 손그림 나무 테두리와 초록 펠트 중앙 카드 받침. **패 이미지와 무관한 게임판 UI**로 안전하게 적용 가능.
- 입력 원본은 사진에서 사선으로 촬영돼 있고 일부 카드 끝이 잘려 있다. 이를 그대로 게임 스프라이트로 자르면 패 비율/식별성이 깨질 수 있어, 정확한 정면 원화 확보 또는 보정 품질 검수 전까지 새 48장 교체를 보류했다.

## 교체 성공 판정

- 48개 카드 ID/월/광/열끗/띠/피/쌍피의 데이터상 대응이 모두 그대로여야 한다.
- 기존 색감·꽃·띠 문양을 원본과 겹쳐 볼 때 캐릭터 외 영역 차이가 없어야 한다.
- 휴대폰 작은 크기에서도 광과 쌍피, 홍단·청단·초단이 식별돼야 한다.
- 자동 저장과 카드 타격·더미 뒤집기·획득 모션을 유지해야 한다.
