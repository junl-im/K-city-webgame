# 꽃맞고 v17 — 착! 손맛과 캐릭터 반응

## 패 한 장의 화면 순서

1. 내 손패 또는 상대 패가 실제 같은 월 바닥패를 향해 곡선으로 날아간다.
2. 바닥패가 살짝 튀고 낸 패가 몇 픽셀 엇갈려 포개지며 `착!` 충돌 링과 꽃잎이 보인다.
3. 더미가 살짝 들썩인 뒤 뒷면 카드가 날아와 앞면으로 뒤집힌다.
4. 더미 카드가 바닥과 매칭된다면 해당 바닥패도 다시 짧게 튄다.
5. 먹은 카드는 기존처럼 실제 획득 위치로 모인다. 이 연출 종료 후 게임 UI 상태가 갱신된다.

## 추가 반응

- 내 캐릭터 밤톨이의 작은 실물 원화가 내 점수 옆에 앉는다.
- 내가 점수를 얻을 때 밤톨이가 환호하며, 상대가 득점할 때 상대 동물이 환호한다.
- 모든 새 파티클은 순수 CSS/DOM 임시 효과다. 화투카드 이미지 자체는 변경하지 않는다.
- `prefers-reduced-motion` 사용자는 추가 모션을 받지 않도록 유지한다.

## 기준과 보존

- 고정 화투 원판 `hwatu-strict90-labeled-atlas-v3.webp` 변경 금지.
- 게임 엔진, 세이브 키, 난이도, 점당 금액, 20초 제한시간, 자동 플레이, 긴급 충전 조건 변경 없음.
- 모바일에서는 가벼운 연출만 사용하고 게임판을 가리는 별도 대형 모달을 추가하지 않음.
