# 꽃맞고 v16 — 꽃놀이마당 인게임 UI 리디자인

## 핵심 원칙

- 기존 승인 화투 원판 `hwatu-strict90-labeled-atlas-v3.webp` 및 48장 월별 색감/문양은 완전 고정한다.
- 라니팡 스타일에서 영감을 얻은 촉감 있는 크림색 패널·입체 버튼·말풍선·동물 캐릭터 모션을 게임 중에도 이어간다.
- 세 친구의 복식·표정·색을 임의로 교체하지 않고 기존 `mascots.png`를 재사용한다.

## 화면별 변화

1. 플레이 HUD — 따뜻한 크림색 상대 캐릭터 카드, 동물의 상황별 반응 모션, 복숭아색 입체 점수 배지.
2. 중앙 게임판 — 기존 원화 테이블/화투패의 선명함 유지, 얇은 벚꽃 광택 장식, 초록·노랑 타이머.
3. 획득 카드 — 상아빛 4분류 패 받침과 민트색 패 칸. 획득된 실제 화투패는 기존처럼 표시.
4. 하단 손패 — 녹색 장난감 받침과 강조된 매칭 힌트, 눌리는 물리 버튼 반응.
5. 고/스톱 및 결과 — 빛나는 아이보리 팝업, 색으로 구분한 정보, 승부 메달의 가벼운 모션.
6. 모바일 — 100svh 안에 모든 게임 구역 유지, 상대·손패·버튼을 단계적으로 압축.

## 변경하지 않은 것

- 패 그림 48장, 카드 순서, 패 내기→맞추기→더미 뒤집기→획득의 타임라인.
- 20초 턴 시간제, 자동모드, 게임 로직, 점수 산정, 무료 충전 조건, 저장 키.

## 검증 범위

- 유닛/게임 회귀 테스트 및 Vite 프로덕션 빌드.
- 데스크톱의 변경 전 게임 화면 기준 디자인 문제점 파악.
- 변경 후 실제 브라우저 재검증은 브라우저 접근 정책으로 제한됨. 모바일 실기기 검수 후 터치 영역과 작은 화면 높이 추가 조정 필요.
