- 한 판 종료 시 ‘내 점수 : 상대 점수’를 큼직하게 보여주고 승리·패배·나가리(무승부) 상태를 다른 색상과 문구로 구분
- 승자에게 실제로 들어온 화투패 중 최근 3장만 원본 화투 이미지로 미리 보여줌. 나가리 상태에서는 승자 패를 노출하지 않음
- 기존 엔진의 finalScore·displayAmount·nextMultiplier·보유 놀이머니 값을 그대로 사용. 게임 점수·AI·머니 정산 규칙은 절대 변경하지 않음
- 결과 화면의 다음 판·긴급 충전(조건 만족 시)·메인 복귀를 손가락으로 누르기 편한 세로 버튼으로 구성. 600px 이하 낮은 화면은 결과 요약을 압축하고 큰 사진 미리보기만 숨김
- 실시간 득점 +N점 팝업 위치를 모바일 뷰포트 안전 범위로 제한해 화면 상하·좌우 잘림 위험 완화. 움직임 감소 설정에선 애니메이션 없이 글씨만 표시
- 기존 v19 동물 화투패, v18 손그림 게임판, v17 WebP 종이 및 버튼 이미지 보존. SVG와 외부 상용 게임 자산 추가 없음
- 테스트: 신규 mobileResultScreenV38.test.js 6개 검증을 기존 213개 테스트에 추가, GitHub CI 통과 전 배포 금지. 실제 스마트폰 화면·터치 QA 별도 필요

## 2026-10-29 · 모바일 큰 선택창과 고/스톱 v37

- '먹을 패 선택' 팝업에서 같은 월의 실제 화투패 2장을 카드별 선택 번호·이름과 함께 큼직하게 배치. 손가락으로 누르기 쉬운 영역과 화면 높이별 보정을 적용
- 선택 가능한 패의 접근성 설명을 기존 '내기'에서 정확한 '먹기'로 수정. '돌아가기'로 취소할 수 있으며 기존 20초 선택 타이머·실제 카드 판정은 유지
- 고/스톱 선택 팝업은 현재 점수를 크게 보여주고 ‘고! 더 치기’와 ‘스톱! 지금 끝내기’ 버튼을 각각 구분된 손그림 종이 질감과 강조색으로 표시. 시간 종료 시 스톱 규칙 유지
- 작은 휴대폰·가로형 낮은 화면에서 팝업이 잘리지 않도록 최대 높이, 내부 스크롤, 카드 폭과 버튼 높이를 조정. 모션 축소 설정도 보존
- 승인된 v19 동물 화투패·v18 손그림 판과 기존 WebP UI 자산 유지. 상용 신맞고 자산·코드·음원 복제 없음, SVG 추가 없음
- 변경은 꽃맞고의 UI·CSS·회귀 테스트만. AI·점수 계산·놀이머니·전체 패 규칙은 변경하지 않음
- 회귀 테스트 `mobileDecisionPanelsV37.test.js` 추가. 브라우저 실기기의 엄지 사용성·레이아웃 육안 검증은 별도 필요

## 2026-10-29 · 모바일 신맞고식 즉시 조작 v36

- 기존 하단 조작 바는 특수 행동이 늘면 화면 바깥까지 가로 스크롤되어 폭탄·흔들기·국진 또는 소리 버튼을 찾기 어려웠음. 모바일에서는 자동 ON/OFF와 소리를 항상 보이는 고정 폭 조작 바에 배치하고, 가능한 특수 행동만큼 ‘✿ 특수 N’ 메뉴를 조건부 노출
- 특수 메뉴를 열면 각 행동의 원래 한국어 명칭(폭탄·흔들기·더미 뒤집기·국진 선택)을 가로 잘림 없는 큰 버튼으로 표시. 버튼은 기존 게임 행동과 그대로 연결되며 고/스톱·판정 로직에는 영향 없음
- PC에서는 이전처럼 특수 버튼을 한 줄에 펼쳐 보여줌. 모바일에서는 자동·특수·소리 세 버튼이 320~430px 가로 안에 들어오게 배치
- 중앙 바닥패 상단의 반복 설명을 모바일에서 숨겨 바닥패에 시선 집중. 메뉴 배경·특수 버튼은 기존 자체 제작 손그림 WebP 질감을 재사용, SVG 신규 사용 없음
- v19 동물 화투패, v18 손그림 게임판, AI·놀이머니·규칙, 창작물 소유권 표기 유지. 화면 겹침 방지 v35 CSS 유지
- 자동 테스트: 신규 모바일 조작 회귀 테스트 포함, GitHub Actions 검증 후 병합. 실제 스마트폰 터치 검증은 별도 필요

## 2026-10-29 · 모바일 UI 겹침 방지 v35

- 320~430px 가로·561~800px 높이의 휴대폰에서 v34 손패 확대가 하단 그리드 공간을 넘길 수 있는 구조적 위험을 수정. 높이별 카드 최대 너비를 설정해 손패가 획득패·버튼 영역에 겹치지 않도록 보강
- 짧은 화면에서는 카드 간 겹침 폭을 함께 완화해 10장이 가로에 들어오면서도 손으로 구분할 수 있도록 조정. 선택 중에는 카드가 위로 솟는 거리를 줄임
- 상단 놀이머니 액수가 긴 경우 금액 텍스트를 말줄임 처리해 홈·도감·도움말 버튼이 오른쪽으로 밀리지 않게 함
- 낮은 화면에서 획득패 그룹의 내부 높이가 그리드 칸을 넘지 않도록 여백 축소
- 기존 v19 동물 화투패, v18 손그림 게임판, 게임 규칙·머니·자동모드와 소유권 표기 유지. SVG 및 새 그래픽 자산 없음
- 검증: 모바일 320·360·390·430px 폭, 화면 높이 561~800px 조합의 세로·가로 카드 배치 계산 회귀 테스트 추가. 실제 휴대폰 브라우저 화면 QA는 별도 필요

## 2026-10-29 · 모바일 손패·바닥패 확대 v34

- 320~430px 세로 휴대폰에서 좌우 여유를 손패와 바닥패의 실제 크기로 돌림. 10장 손패는 안전 여백 안에서 모두 보이는 겹침 폭 유지
- 바닥패는 일반·혼잡·많이 혼잡한 상태별로 크기를 다르게 적용해 복잡한 판에서도 스크롤과 시야 이탈을 줄임
- 700px 이하 짧은 화면은 별도 완만한 확대로, 560px 이하 아주 짧은 화면은 이전 안전한 크기로 유지. 320px 미만 접는 화면을 위한 겹침 범위 별도 지정
- 터치스크린에서 데스크톱 hover 상태가 붙어 손패가 튀는 현상을 방지. 선택 터치 미리보기와 키보드 포커스는 유지
- 기존 v19 동물 화투패, v18 손그림 판, 점수·규칙·머니·특수 모션 변경 없음. 새 SVG나 CSS 기하학 장식 없음

## 2026-10-29 · 터치 카드 고정과 손그림 착지 효과 v33

- 모바일에서 겹친 손패를 터치하면 Pointer Capture로 누르기 시작한 카드에 입력을 고정. 패가 들리는 애니메이션 때문에 이웃 카드가 눌리는 현상 방지
- 보통 패의 바닥패 접촉 시 원형 CSS 링 대신 기존 WebP 꽃잎 도장으로 짧게 반응. 패 그림·점수 계산·턴 순서는 변경하지 않음
- 키보드 클릭과 마우스 입력 및 Pointer Capture 미지원 환경은 기존 한 번 누르기 동작 유지
- 동작 줄이기 설정 사용자는 꽃잎 애니메이션 표시 안 함. 새로운 SVG나 외부 게임 자산 없음
- 공개 저작권 문서에서는 사용자의 개인정보인 실명을 제거하고 ‘곰같은여우’ 명의만 유지
