# 꽃맞고 개발 변경 기록

## 2026-10-29 · 모바일 UI 겹침 방지 v35

- 320~430px 가로·561~800px 높이의 휴대폰에서 v34 손패 확대가 하단 그리드 공간을 넘길 수 있는 구조적 위험을 수정. 높이별 카드 최대 너비를 설정해 손패가 획득패·버튼 영역에 겹치지 않도록 보강
- 짧은 화면에서는 카드 간 겹침 폭을 함께 완화해 10장이 가로에 들어오면서도 손으로 구분할 수 있도록 조정. 선택 중에는 카드가 위로 솟는 거리를 줄임
- 상단 놀이머니 액수가 긴 경우 금액 텍스트를 말줄임 처리해 홈·도감·도움말 버튼이 오른쪽으로 밀리지 않게 함
- 낮은 화면에서 획득패 그룹의 내부 높이가 그리드 칸을 넘지 않도록 여백 축소
- 기존 v19 동물 화투패, v18 손그림 게임판, 게임 규칙·머니·자동모드와 소유권 표기 유지. SVG 및 새 그래픽 자산 없음
- 검증: 모바일 320·360·390·430px 폭, 화면 높이 561~800px 조합의 세로·가로 카드 배치 계산 회귀 테스트 추가. 실제 휴대폰 브라우저 화면 QA는 별도 필요

## 2026-10-29 · 모바일 손패·바닥패 확대 v34

- 320~430px 세로 휴대폰에서 좌우 여유를 손패와 바닥패의 실제 크기로 돌림. 10장 손패는 안전 여백 안에서 모두 보이는 겹침 폭 유지
- 바닥패는 일반·혼잡·많이 혼잡한 상태별로 크기를 다르게 적용해 복잡한 판에서도 스크롤과 시야 이탈을 줄임
- 700px 이하 짧은 화면은 별도 완만한 확대로, 560px 이하 아주 짧은 화면은 이전 안전한 크기로 유지. 320px 미만 접는 화면을 위한 겹침 범위 별도 지정
- 터치스크린에서 데스크톱 hover 상태가 붙어 손패가 튀는 현상을 방지. 선택 터치 미리보기와 키보드 포커스는 유지
- 기존 v19 동물 화투패, v18 손그림 판, 점수·규칙·머니·특수 모션 변경 없음. 새 SVG나 CSS 기하학 장식 없음

## 2026-10-29 · 터치 카드 고정과 손그림 착지 효과 v33

- 모바일에서 겹친 손패를 터치하면 Pointer Capture로 누르기 시작한 카드에 입력을 고정. 패가 들리는 애니메이션 때문에 이웃 카드가 눌리는 현상 방지
- 보통 패의 바닥패 접촉 시 원형 CSS 링 대신 기존 WebP 꽃잎 도장으로 짧게 반응. 패 그림·점수 계산·턴 순서는 변경하지 않음
- 키보드 클릭과 마우스 입력 및 Pointer Capture 미지원 환경은 기존 한 번 누르기 동작 유지
- 동작 줄이기 설정 사용자는 꽃잎 애니메이션 표시 안 함. 새로운 SVG나 외부 게임 자산 없음
- 공개 저작권 문서에서는 사용자의 개인정보인 실명을 제거하고 ‘곰같은여우’ 명의만 유지

## 2026-10-29 · 모바일 게임판 우선 UI v32

- 기존 손그림 게임판과 캐릭터 화투패 v19는 변경하지 않고, 모바일의 시선 흐름을 상대 점수 → 바닥패 → 큰 내 손패 → 자동/특수 동작으로 정돈
- 320~430px 세로 휴대폰에서 손패를 더 키우고 적당히 겹쳐 펼쳐 10장도 가로로 넘치지 않게 조정
- 바닥패 수량(일반·혼잡·가득 참)에 따라 패 크기를 유지·조절해 가운데 판을 넓게 사용
- 헤더 설명·상대 패 뒷면·획득패 장식 같은 부가 요소를 모바일에서 압축하며, 획득패·타이머·자동모드·소리 조절 기능은 유지
- 700px 이하 저높이 화면과 560px 이하 초단신 화면을 따로 조정, `100svh`와 안전영역 적용
- 새 디자인 자산 및 SVG 없음. 게임 로직·배포 설정은 변경하지 않음
