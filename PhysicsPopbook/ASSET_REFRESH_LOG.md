# PhysicsPopbook v2.7 — 신규 원화 자산 대장

권리 표기: **© 2026 곰같은여우. All rights reserved.**

이 문서는 물리도감 프로젝트를 위해 별도 생성·도입한 래스터 원화 자산의 관리 기록입니다. 외부 오픈소스와 서드파티 라이브러리는 각 라이선스를 별도로 따릅니다.

| 자산 | 칸 배치 (2×2) | 쓰임 | 보존 원칙 |
| --- | --- | --- | --- |
| `dist/assets/physics-surface-atlas-v18.png` | 좌상 펠트 / 우상 얼음 / 좌하 목재 / 우하 흙·자갈 | 마찰 경사판, 실험 바닥, 물통 바닥, 선택 UI | 기존 `physics-surface-atlas-v17.webp`는 백업·실패 대체용으로 계속 보존 |
| `dist/assets/physics-apparatus-materials-v01.png` | 좌상 황동 / 우상 강철 / 좌하 고무 / 우하 도자기 | 경사판 고정 볼트, 진자 축·금속 장치 | 신규 자산이 없을 때는 코드의 기존 물성 표현 색상 사용 |

- 제작 방식: 생성형 이미지 도구로 새 래스터 재료 질감을 생성하고, 원본 PNG 품질을 보존
- 시각 목표: 동화풍 3D 미니어처 실험 기구의 촉감, 고유한 소재, 분명한 물체 접촉점
- 구현 방식: Canvas 소스 이미지의 정확한 2×2 영역 잘라 사용; 물리 법칙 계산과 분리
- 안전 점검: 모듈 버전 일치 테스트, 아틀라스 크롭 범위·원화 누락 대체, 회전축/바닥 접지 검사
- 금지사항: 신규 SVG로 원화를 대체하지 않음, 이전 이미지 일괄 덮어쓰기 금지, 개인 실명 공개 금지

## 관리 기준

GitHub `PhysicsPopbook/`가 정본이며, 노션과 구글드라이브에는 변경 로그·이미지 명세·QA 기록을 병행 기록합니다.
