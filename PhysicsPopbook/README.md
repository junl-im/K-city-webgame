## 현재 구현

- 마법책 첫 화면과 직접 생성한 WebP 원화, 따뜻한 구름 하늘과 장난감 디오라마 배경, 네 동물 친구의 부드러운 움직임
- 동화책 목차 12장, 문장을 누르면 곧바로 해당 조건의 실험이 실행되는 상호작용
- WebGL 기반 3D 쇠구슬·깃털 낙하 실험
- WebGL 기반 3D 태양·지구·가상 탐사 행성 공전 실험. 거리 0.6~1.8 AU와 공전 주기를 비교
- WebGL 기반 3D 평면거울·광선 반사 실험. 법선 기준 입사각 10~70°를 바꾸며 반사각을 비교
- WebGL 기반 3D 전기회로 실험. 전지·전구·스위치와 전류 경로를 관찰하고 화면에서 스위치를 직접 누르며 전압(1.5~9V)·저항(3~12Ω)을 조절
- 옴의 법칙(`I = V/R`) 및 전력(`P = VI`) 계산, 회로 단절 때 전류·전력 0, 학습용 전구 발광 효과와 움직이는 전류 표시
- WebGL 3D/Canvas 2D 지레·도르래 실험. 지레 힘점 거리 1~4m, 하중 60~240N, 고정/움직도르래 전환, 입력 이동 거리와 필요한 힘 시각화
- 자석과 철구/나무 구슬 비교 실험. 자석 거리·세기를 바꾸어 끌리는 모습을 질적으로 탐색(실제 자기력 수치로 오해하지 않도록 계산 모델과 연출 분리)
- 북소리 실험. 진동수와 세기를 바꾸고 공기 중 파장(가정 음속 340m/s)을 비교하며 짧은 소리도 직접 듣기
- 관성 실험. 귀여운 곰의 사과 수레가 천천히 멈추거나 급정거할 때, 처음 속도와 일정한 감속을 바꾸어 정지 거리·시간을 비교
- 마찰 실험. 얼음길과 거친 길에서 장난감 미끄럼틀의 경사를 바꾸어 미끄러지는 조건과 가속도를 비교
- 부력 실험. 고양이와 오리 장난감이 있는 물놀이 그림에서 뜨는 오리와 가라앉는 돌, 민물과 소금물의 차이를 비교
- 진자 실험. 달과 지구에서 그네 줄의 길이를 바꾸며 한 번 왕복하는 시간의 차이를 계산하고 흔들림을 관찰
- 열 실험. 따뜻한 물 1~2컵의 온도와 얼음의 무게를 바꾸어 녹는 양과 섞인 뒤 온도를 비교
- 새로운 5개 장면은 가벼운 Canvas 2D 애니메이션과 독립된 물리 계산 모형을 사용. 광택·그림자·입체 질감이 살아 있는 WebP 장난감 원화를 움직여 모바일 부담을 줄임
- v0.9에서는 한 장의 그림을 흔들던 방식을 바꿔 사과·운동화·오리/돌·진자 추·얼음이 독립적으로 반응하도록 구현. 관성의 상대 움직임, 마찰 가속도에 따른 이동, 뜨기/가라앉기, 진자 주기, 얼음의 녹은 비율을 각 소품에 연결
- v1.0에서는 모든 12장 실험에 동물 친구 4종이 과학 상태별 짧은 설명·기쁨·호기심 반응으로 참여. 기존 WebP 원화와 CSS 움직임을 재사용하고 모바일에서는 작은 말풍선으로 표시
- v1.0에서는 9종 투명 WebP 장난감 원화(`dist/assets/physics-toys-atlas-v10.webp`, 316KB)를 3×3 컷으로 재사용하여 중력·행성·반사·회로·지레 등 기존 실험의 2D 소품도 입체적으로 개선. 모바일은 그림책 실험으로 즉시 시작하며 3D는 선택 시 로드
- v1.1에서는 기존 WebP 원화를 그대로 살리면서 모든 12장 실험의 별도 Canvas 장식 효과를 확장. 낙하 후 바닥 파문·속도 잔상, 공전 궤적, 반사광의 이동 광점, 회로 전구 반짝임, 진동수에 따른 소리 파동 간격, 자기장 시각 안내, 지레 완료 반응 등을 추가

- v1.2에서는 320px/375px 모바일 작은 화면에서 반복되던 캔버스 문구를 생략해 안내 배지와 겹치지 않도록 조정하고, 합성 음 듣기 버튼을 의미에 맞게 수정. 모든 새 삽화는 투명 WebP로 분리하여 원래의 장난감 질감을 보존

- v1.3에서는 별 장식 황동·나무 도르래 바퀴와 목재 지레 받침점을 투명 WebP 소품으로 새로 제작, 조건에 따라 바퀴를 회전·지레를 기울이는 애니메이션에 사용. 모바일에서는 곰 말풍선을 실험 장치에서 떨어뜨리고 중복된 캔버스 설명을 생략
- v1.3에서는 과학 문구도 검수하여 고정도르래에는 힘의 방향만 바뀌고 힘·이동 거리의 이득은 없다는 사실을 명시하고, 움직도르래에는 힘 절반·당기는 거리 두 배를 명확히 설명
- v1.4에서는 켜지지 않은 회로에도 이미 빛나는 전구가 보이던 원화 오류를 수정. 전구의 투명 유리·꺼진 필라멘트를 별도 투명 WebP로 제작하고 실제 전력에 따른 밝은 원화와 후광을 단계적으로 합성. 연결된 스위치 전류 입자 경로도 빈 구간 없이 연속 이동
- v1.4에서는 빛 반사 장면의 장식용 거울 중복을 없애고 실제 반사면의 황동 프레임, 각도에 따라 방향이 변하는 손전등, 입사·반사 방향 화살표를 보강
- v1.4에서는 공전 장면의 단색 탐사 점을 보라색 행성 캐릭터로 교체하고, 가까운 궤도에서 태양과 행성 그림이 겹치지 않도록 모바일 원화 크기를 수학적으로 제한
- v1.4 모바일 실제 렌더링 검수에서 복잡한 광선·전선·공전도 위를 가리는 동물 말풍선은 해당 세 장에 한해 숨기고, 별도 상태 문구는 유지. 반사점과 회로 부품을 덮던 중복 시간 배지를 제거하고 320px의 하단 안내 줄바꿈을 정리
- v1.5에서는 관성 장면의 수레 이동 거리를 물리 모델의 정지 거리와 연계해 속도·제동 방식에 맞게 조정. 경사면은 실제 선택한 10~40도 각도로 그리며 신발 방향과 접점을 경사면에 맞춤. 부력 장면은 오리의 넓은 몸통만 물속에 잠기도록 원화 높이를 보정하고, 물속 부피와 화면 높이가 다른 점을 구분해 결과 문구 수정. 모바일에서는 중복 캔버스 문구와 결과 배지·가리는 캐릭터를 숨겨 실험 소품을 보호. 화면 배치와 계산 연결을 테스트로 검증
- v1.6에서는 책·재생·조작 손잡이·사과·수레·얼음·오리·돌·거울을 일관된 동화 장난감풍 원화 9종으로 제작하고, 3×3 투명 WebP 아틀라스 하나로 최적화. 모바일 하단 이야기/조작/원리/시작 메뉴, 실험 이야기 선택지, 실험 조건(관성·마찰·부력), 설명·퀴즈·첫 화면 버튼에 연결. 물리 수치·방향·각도·과학 상태 표식은 알아보기 쉽고 정확하게 유지

## 알려진 제약

- 이 버전은 중력·공전·빛의 반사·전기회로·지레/도르래·자석·소리·관성·마찰·부력·진자·열 12개 단원이 작동하며 AI 놀이터 본체와 아직 결합하지 않았습니다.
- 메인 마법책, 여우 박사 및 곰·고양이·토끼 시그니처 캐릭터 모두 투명 WebP로 연결했습니다. 정식 버튼 원화는 후속 작업 대상입니다.
- 공기 저항은 `F_drag = k*v*|v|`로 단순화했습니다. 질량과 저항 계수는 교육용 대표값이며 실물 깃털 측정값은 아닙니다.
- 달은 거의 대기가 없으므로 자동 진공 모드로 전환합니다.
- 공전 모형은 태양 중심, 원형 궤도, `T² = r³`(년/AU)를 사용하며 크기와 거리 비율은 실제와 다릅니다.
- 빛 반사는 평면거울의 법선을 기준으로 계산합니다. 움직이는 점은 학습 연출로 실제 광자나 빛의 속도를 재현하지 않습니다.
- 전기회로는 일정한 저항의 가상 전구 모델이며 실제 백열전구의 온도에 따른 저항·최대 정격을 재현하지 않습니다. 전구 밝기와 움직이는 점은 전력 및 전류를 설명하기 위한 시각 효과입니다.
- 지레·도르래는 마찰, 물체·장치의 무게와 변형을 무시한 이상적 모형이며 입력 일과 출력 일이 같도록 계산합니다. 움직도르래에 연결된 줄의 2가닥을 하중 지지로 가정합니다.
- 자석은 철과 나무의 정성적인 차이만 표현합니다. 거리와 세기 슬라이더는 시각 효과의 크기를 조절하며 실제 자기력·자속밀도를 계산하지 않습니다.
- 소리는 공기 중 음속을 340m/s로 고정한 단순 모델이고 파장은 음속/진동수로 계산합니다. 화면의 링은 이해를 위한 표현이며 실제 소리의 전달 모양과 다릅니다.
- 관성 장면은 수레의 감속도를 일정하다고 가정하고 사과의 앞으로 쏠림을 연출합니다. 실물 충돌·안전 성능을 예측하는 모델이 아닙니다.
- 마찰 장면은 정지·운동 마찰계수 차이를 단순화하고 표면별 고정된 대표 계수를 사용합니다.
- 부력 장면은 물과 물체의 밀도만을 고려하며, 소금물 농도와 밀도의 관계는 학습용 근삿값입니다.
- 진자 장면의 주기는 작은 진폭을 가정한 근삿값이며, 진폭을 바꿨을 때 큰 진폭 효과는 계산하지 않습니다.
- 열 장면은 얼음이 처음 0℃라고 가정하고 주위로 열이 새지 않는 이상적인 혼합을 계산합니다. 실제로 뜨거운 물과 얼음을 만지는 실험은 보호자 지도 아래에서만 해야 합니다.
- 새 장면의 그림 속 물체 위치·크기·움직임은 원리 설명을 위한 연출이며, 표시된 계산값과 일대일로 비례하는 실제 축척 애니메이션은 아닙니다.
